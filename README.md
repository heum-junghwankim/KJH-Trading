# KJH-Trading

CEO 매매 차트(**CME_MINI:NQ1! 일봉**)에 올라간 **5개 지표 — Auto VWAP · VRVP · Volume-Pressure-Tracker · Triple-Stochastic-Wave · cRSI** — 의 사용 설명서입니다. 하나의 신호가 아니라 **여러 지표가 한 방향으로 정렬됐는지 교차 검증**하는 것이 핵심입니다.

핵심 원칙은 단순합니다 — **신호 하나를 믿지 않는다.** 국면(Auto VWAP) + 레벨(VWAP 밴드·VRVP·거래량 가중선) + 모멘텀(삼중 스토캐스틱·cRSI) + 거래량(압력)이 같은 방향일 때만 자리로 봅니다.

## 1. 현재 차트 지표 5종 가이드

CEO 매매 차트(CME_MINI:NQ1! 일봉)에 올라간 5개 지표를 **쉽게** 정리합니다. 지표마다 `무엇을 보여주나 → 차트에서 읽는 법 → 매매에 쓰는 법 → 주의점` 순서입니다. 저장소에 소스가 있는 4종(Auto VWAP·거래량 압력·삼중 스토캐스틱·cRSI)은 `.pine` 소스 기준이고, VRVP는 TradingView 내장 지표라 일반 정의로 설명합니다.

| 지표 | 한 줄 역할 | 주로 쓰는 곳 |
| --- | --- | --- |
| **Auto VWAP** (overlay) | 평균 체결 단가·밴드·이평 리본·추세/전환가 테이블 | 국면 규정, 지지/저항, 손절선 |
| **VRVP** (overlay, 내장) | 가격대별 거래량(매물대) | 지지/저항 레벨·목표가 |
| **Volume-Pressure-Tracker** | 매수/매도 압력 추정·비정상 거래량 | 움직임에 힘이 실렸는지 확인 |
| **Triple-Stochastic-Wave** | 3개 스토캐스틱 서열(정배열/역배열) | 단기 방향·타이밍 |
| **cRSI** | 사이클 평활 RSI + 동적 밴드 | 과열/과매도·다이버전스 |

> **공통 리스크 원칙** — ① 어느 지표도 **단독 진입 근거가 아닙니다**. 국면(Auto VWAP 추세 확인) + 레벨(VWAP 밴드·VRVP·50/100/200선) + 모멘텀(스토캐스틱·cRSI) + 거래량(압력)이 한 방향일 때만 자리로 봅니다. ② 판단은 **마감봉(완성봉) 기준**입니다. `실시간봉` 값은 형성 중인 봉에서 틱마다 바뀌는 참고값입니다. ③ 진입 전 손절가를 먼저 정하고, 손익비(R:R)가 안 나오면 들어가지 않습니다.

### 1-1. Auto VWAP

**무엇을 보여주나** — 최근 20봉 거래량 가중 평균 단가(VWAP)와 ±2σ 밴드를 중심으로, 지수 리본(EMA/DEMA/TEMA)·거래량 가중 50/100/200선·Sonar 모멘텀 배경·우측 상단 상태 테이블을 한 지표에 묶었습니다. 소스: [`auto-vwap.pine`](./pinescript/VWAP/auto-vwap.pine) · 상세: [VWAP README](./pinescript/VWAP/README.md)

**차트에서 읽는 법**

| 요소 | 모양·색 (기본값) | 의미 |
| --- | --- | --- |
| Band #2 세트 A / B | 대시 흰색(최근 20봉) / 도트 회색(최근 50봉), VWAP ±2σ | 과확장 감시선. 밖으로 나가면 과열/과매도이지만 강한 추세에선 바깥에 오래 머뭄 |
| VWAP 중앙선 | 흰 점선, **기본 숨김**(`VWAP 중앙선 표시` OFF) | 평균 단가 기준선. 위=매수 우위, 아래=매도 우위 |
| 지수 리본 | EMA 노랑 · DEMA 하늘 · TEMA 분홍 (길이 20) | 세 선의 순서·기울기로 단기 추세 국면 |
| 거래량 가중선 | 50선 딥 오렌지 `#FF6D00` · 100선 파랑 · 200선 보라 (기본 VWMA) | 단기·중기·장기 지지/저항, 추세 확인 테이블의 비교 대상 |
| Sonar 모멘텀 배경 | 차트 전체, 투명도 85 | Sonar(=EMA20 − EMA20의 9봉 전) vs Signal(EMA9) 교차로 상승/하락. 밴드워킹 연동 4색: **골든+상승 워킹=파랑 `#2196F3`**, 골든 그 외=녹 `#2E7D32`, **데드+하락 워킹=빨강 `#C62828`**, 데드 그 외=주황 `#FF6D00` |
| %R 다이버전스 원 | 강세=하늘색 원(봉 아래) · 약세=핑크 원(봉 위) | Williams %R(20) 다이버전스. 반전 주의 표시 |
| 비정상 캔들색 | 비정상 매수(과매수)=붉은 캔들 · 비정상 매도(과매도)=파랑 캔들 | cRSI 과열 + 볼린저 이탈 동시 충족 봉 |

**매매에 쓰는 법** — ① 먼저 테이블 `추세 확인`(단기·중기·장기)으로 국면을 정합니다. ② 배경이 **파랑**(골든+상승 워킹)이면 상승 추세 진행, **빨강**(데드+하락 워킹)이면 하락 추세 진행, 녹/주황은 방향은 있으나 추세 강도가 약한 구간으로 읽습니다. ③ 진입·청산 가격은 `기울기/교차 전환가`·`지지·저항 임계가`의 **가격**을 손절·트리거 기준으로 씁니다.

**주의** — Sonar 배경·비정상 캔들색·`실시간봉` 섹션 값은 형성 중 봉에서 틱마다 바뀌고 봉 마감 때 확정됩니다(과거 봉은 바뀌지 않음). 전환가는 "이 가격으로 마감하면 바뀐다"는 **조건부 가격이지 예측이 아닙니다.**

#### Auto VWAP 상태 테이블 — 섹션별 정리

**배치** — `테이블 레이아웃` input: 기본 `가로형`(5개 섹션을 왼쪽→오른쪽, 10열×5행) / `세로형`(2열×21행, 위→아래). 셀 내용·색은 동일하고 위치만 다릅니다. (현재 CEO 차트는 `세로형`으로 설정되어 있습니다.)

**기준봉** — 섹션 헤더 제목 뒤 괄호가 그 섹션의 기준봉입니다(예 `추세 확인 (완성봉)`). `완성봉` = 가장 최근 확정봉(형성 중이면 직전봉) 기준, 틱 변동에 고정, %는 그 봉 종가 대비 / `실시간봉` = 현재 형성 중 봉 기준, 틱마다 갱신, %는 현재가 대비.

| 섹션 (순서) | 기준봉 input | 기본 |
| --- | --- | --- |
| ① 추세 확인 | `기준봉: 추세 확인` | 완성봉 |
| ② 기울기 전환가 | `기준봉: 기울기 전환가` | 실시간봉 |
| ③ 교차 전환가 | `교차 전환가` (기울기 전환가와 같은 줄) | 실시간봉 |
| ④ 변동성 임계가 | `기준봉: 변동성 임계가` | 실시간봉 |
| ⑤ 지지·저항 임계가 | `지지·저항 임계가` (추세 확인과 같은 줄) | 완성봉 |

**색 약속** — 청록 `#0E9C8A` = 상승 계열, 자홍 `#C2185B` = 하락 계열, 회색 = 중립·데이터 부족. 지지/저항 행만 녹/빨강(선명=지지·저항 판정, 둔탁=단순 위·아래)을 씁니다.

##### ① 추세 확인 (기본 완성봉) — 확정된 추세 방향 (후행)

| 행 | 비교 | 값 | 셀 색 | 트레이딩 해석 |
| --- | --- | --- | --- | --- |
| `단기추세` | VWMA 20선 vs 50선 | `골든 크로스`/`데드 크로스`(크로스 봉), 그 외 `(강한/약한) 상승·하락 (+x.x% \| N봉)` — %=크로스 시점 대비 빠른 선 변화율, N봉=크로스 후 경과봉. 데이터 부족 `-` | 상승=청록·하락=자홍. 크로스·강한=선명, 보통=중간, 약한=옅음 | 전환가 신호가 실제 추세로 이어졌는지 검증 |
| `중기추세` | VWMA 50선(주황) vs 100선 | 위와 같은 형식 | 위와 같음 | 스윙 방향. 단기와 엇갈리면 관망 |
| `장기추세` | 100선 vs 200선 | 위와 같은 형식 (200봉 미만 `-`) | 위와 같음 | 최상위 방향 필터. 역행 진입은 피하거나 비중 축소 |

- `강한` = 크로스 후 5봉(`추세 폭 변화 판정 봉수`)이 지난 뒤 두 선 간격이 넓어지는 중, `약한` = 간격이 좁아지는 중이거나 간격이 4%(`크로스 주의 간격`) 이하로 반대 크로스가 가까움. 크로스 직후 5봉 동안은 강약 없이 `상승`/`하락`만 표시합니다.

##### ② 기울기 전환가 (기본 실시간봉) — 이평선이 꺾이는 가격

| 행 | 값 예시 | 이 가격으로 마감하면 | 셀 색 (현재 상태) | 트레이딩 해석 |
| --- | --- | --- | --- | --- |
| `TEMA 전환` | `상승전환 : 10,215 (+2.1%)` / `하락전환 : …` | TEMA의 1봉 기울기 부호가 바뀜 | TEMA 상승 중=청록 · 하락 중=자홍 | 가장 빠른 1차 트리거. 휩쏘가 많아 소액·단독 금지 |
| `DEMA 전환` | 위와 같은 형식 | DEMA 기울기 부호가 바뀜 | DEMA 상승 중=청록 · 하락 중=자홍 | 진입 확인·비중 확대(TEMA→DEMA 단계 진입). 반대 포지션은 이 가격 너머 마감 시 청산 |
| `정배열 전환` | `정배열 : 10,480 (+4.8%)` (이미 정배열이면 `-`) | 세 선 1봉 기울기가 TEMA > DEMA > EMA | 정배열=청록 · 역배열=자홍 · 중립=회색 (두 행 공통) | 롱 정찰 기준. **근사값**이라 마감 후 셀 색 전환을 확인 |
| `역배열 전환` | `역배열 : 9,870 (-1.3%)` (이미 역배열이면 `-`) | 세 선 1봉 기울기가 EMA > DEMA > TEMA | 위와 같음 | 롱 축소·숏 정찰 기준. 근사값 |

- 배열 판정의 노이즈 필터는 `밴드 배경 필터` input(기본 `정규화 갭`)을 따릅니다.

##### ③ 교차 전환가 (기본 실시간봉) — 두 선 교차가 바뀌는 가격

| 행 | 값 예시 | 이 가격으로 마감하면 | 셀 색 | 트레이딩 해석 |
| --- | --- | --- | --- | --- |
| `Sonar 교차` | `하락교차 : 9,950 (-0.5%)` / `상승교차 : …` | Sonar가 Signal을 교차해 배경 방향이 뒤집힘 | Sonar 상승=청록 · 하락=자홍 · 워밍업=회색 | 가장 이른 반전 경보. 보유 포지션 일부 익절·손절 당기기용, 이것만으로 진입하지 않음 |
| `T/D 교차` | `골든교차 : 11,750 (+17.5%)` / `데드교차 : …` | TEMA가 DEMA를 교차 | 골든=청록 · 데드=자홍, 저채도(`#6E8F72` 골든 되돌림 중 / `#A57A7A` 데드 압력 완화 중) | 전환이 확정되는 가장 늦은 단계. 새 방향 본진입 기준이자 **반대 포지션의 최종 손절선** |

**②·③ 공통 표시 규칙** — 가격은 틱 단위로 반올림(상향 전환은 올림·하향은 내림), %는 기준봉 종가 대비. 전환가가 0 이하이거나 ±50%를 넘으면 `도달불가`, 계산 전이면 `-`, `리본 소스`가 `종가`가 아니면 TEMA/DEMA/배열/T/D 행은 `소스≠종가`.

##### ④ 변동성 임계가 (기본 실시간봉) — 밴드워킹·과열 정도

| 행 | 값 | 셀 색 | 트레이딩 해석 |
| --- | --- | --- | --- |
| `상승확장(20)` | 기준봉이 **횡보**면 `상승 : 가격 (±%)`(상승 워킹이 되는 종가), **상승 워킹**이면 `횡보 : 가격`(워킹이 풀리는 종가), **하락 워킹**이면 `-` | 기준봉 밴드워킹 상태: 상승 워킹=청록 · 하락 워킹=자홍 · 횡보=회색 (두 행 공통) | 상승 워킹 = 밴드를 타고 오르는 추세 → 롱 보유·눌림 추가 근거. `횡보 :` 가격은 롱 익절·손절을 당기는 기준 |
| `하락확장(20)` | 위의 대칭 (`하락 : …` / `횡보 : …` / 상승 워킹이면 `-`) | 위와 같음 | 하락 워킹 = 숏 보유·롱 보류 근거. `횡보 :` 가격은 숏 익절·손절 기준 |
| `이격도 (20)` | `값 (중립/되돌림 주의/되돌림 확실)` — 종가 ÷ SMA20 × 100 | 과열 확실=빨강 · 과매도 확실=초록 · 주의=둔탁 빨강/둔탁 녹 · 중립=회색 | 과열 방향 추격 진입 자제. 강한 추세에선 과열이 오래가므로 역추세 단독 근거로 쓰지 않음 |
| `되돌림 가격` | 이격도가 중립으로 돌아오는 경계 가격 `(±%)`, 과열 아니면 `-` | 회색 | 과열 방향 포지션의 청산 목표·눌림 재진입 기준(도달 보장 아님) |

- 밴드워킹 판정(N=`밴드워킹 판정 기간`, 기본 20): 종가가 +1σ 밖 + VWAP 5봉 기울기 상승(또는 기울기 평탄 + 밴드폭 확장)이면 상승 워킹, 하락은 대칭. ±2σ 밖으로 이탈한 봉은 워킹에서 제외. 가격은 다음 봉 거래량=기준봉 거래량으로 가정한 **수치 탐색 근사**이며 ±50% 초과는 `도달불가`.
- 이격도: 고정 임계(±10%)와 적응형 임계(최근 50봉 1.5σ) 중 1개 충족=`되돌림 주의`, 2개=`되돌림 확실`.
- Sonar 배경의 파랑/빨강/녹/주황 구분도 이 밴드워킹 판정을 그대로 씁니다.

##### ⑤ 지지·저항 임계가 (기본 완성봉) — 거래량 가중선 레벨

| 행 | 값 | 셀 색 | 트레이딩 해석 |
| --- | --- | --- | --- |
| `50선` | VWMA 50선 가격 `(기준봉 종가 대비 ±%)` — 선이 위면 `+`, 아래면 `−` | 지지=녹 · 저항=빨강 · 단순 위=둔탁 녹 `#6E8F72` · 단순 아래=둔탁 빨강 `#A57A7A` · 선 없음=회색 | 단기 눌림 진입·손절 기준. 지지 판정에서 아래 마감 → 롱 손절 검토, 저항 판정에서 위 마감 → 숏 손절 검토 |
| `100선` | 100선 가격 `(±%)` | 위와 같음 | 중기 매물대. 지지 유지=추세 지속, 종가 이탈=반전 경계 |
| `200선` | 200선 가격 `(±%)` | 위와 같음 | 대추세 최종 지지/저항. 종가 돌파·이탈 = 장기 국면 전환 |

- 지지/저항 판정은 각 선 ± (1.0 × 거래량 가중 표준편차) 판정 밴드와 근처 구간(%)으로 평가합니다. 셀에는 가격만 보이고 판정 결과는 **셀 색**으로 읽습니다.

> 근거: `pinescript/VWAP/auto-vwap.pine` — 테이블 input(91~117행), 섹션별 기준봉 오프셋(939~948행), 추세 확인 셀(1102~1194행), 지지·저항 셀(1236~1303행), 이격도·되돌림(1308~1317행), 셀 툴팁(1331~1344행), 전환가 텍스트·색(1346~1409행), 상승/하락확장 행(1410~1538행), 렌더링·레이아웃(1551~1618행). 판정 파라미터는 전략성 값이므로 변경 시 알고리즘 수학자 검토가 필요합니다.

### 1-2. VRVP (Visible Range Volume Profile — TradingView 내장)

**무엇을 보여주나** — 지금 **화면에 보이는 구간**의 거래량을 **가격대별 가로 막대**로 쌓아, 어느 가격에서 거래가 많이(매물대) 또는 적게 일어났는지 보여줍니다.

**차트에서 읽는 법**

| 요소 | 의미 |
| --- | --- |
| 가로 막대 | 그 가격대의 누적 거래량. 현재 차트는 `Volume = Up/Down`이라 상승봉/하락봉 거래량이 나뉘어 표시 |
| POC (Point of Control) | 거래량이 가장 많은 가격 — 가장 강한 균형점·자석 가격 |
| Value Area (VAH/VAL) | 전체 거래량의 일정 비율(현재 차트 `Value Area Volume = 70`%)이 몰린 가격 범위의 상단/하단 |
| 두꺼운 구간 / 얇은 구간 | 두꺼운 곳(HVN)=지지/저항·횡보가 일어나기 쉬움, 얇은 곳(LVN)=가격이 빠르게 통과하기 쉬움 |

(현재 차트 설정: `Rows Layout = Number Of Rows`, `Row Size = 120`, `Volume = Up/Down`, `Value Area Volume = 70`.)

**매매에 쓰는 법** — VAH/VAL·POC를 지지/저항·목표가 후보로 쓰고, Auto VWAP 밴드·50/100/200선과 **겹치는 가격**일수록 신뢰도를 높게 봅니다. 얇은 구간(LVN)에 진입하면 다음 두꺼운 구간까지 빠르게 이동할 수 있다는 가정으로 목표를 잡습니다.

**주의** — 화면을 스크롤·확대하면 계산 구간이 바뀌어 **프로파일 자체가 달라집니다**(같은 차트라도 보는 범위에 따라 POC가 이동). 레벨을 기록할 때는 어떤 구간 기준인지 함께 남깁니다. 연속 선물(NQ1!)은 만기 롤오버 구간의 거래량이 섞일 수 있습니다.

### 1-3. Volume-Pressure-Tracker (거래량 압력)

**무엇을 보여주나** — 각 봉의 거래량을 **종가 위치로 매수/매도 몫으로 나눠** 추정하고, 평소보다 큰 **비정상 거래량**과 최근 압력 방향을 보여줍니다. 소스: [`volume-pressure-tracker.pine`](./pinescript/VOLUME-PRESSURE/volume-pressure-tracker.pine)

**차트에서 읽는 법**

| 요소 | 의미 (기본값) |
| --- | --- |
| 거래량 막대 | 전체 거래량 막대(매도색) 위에 매수 추정 몫(매수색)을 겹쳐 그림. 매수 몫 = `volume × (종가 − 저가)/(고가 − 저가)` |
| 막대 색 | 정상 봉: 매수=흰색·매도=회색 / **비정상 봉**: 매수=라임·매도=빨강. 비정상 = `volume > SMA(volume, 비교 캔들 수) × (1 + 비정상 배수)`, 기본 `20`·`1.0` → 20봉 평균의 **2배 초과** |
| 주황 선 | 거래량 평균(SMA, `평균선 봉 수` 기본 20) — 현재 거래량이 평소보다 실제로 큰지 확인 |
| 테이블 `거래량 압력` | 현재 봉 거래량이 평균선 위 + 매수 몫 우세=`롱 유리`(녹), 매도 몫 우세=`숏 유리`(빨강), 평균선 아래=`중립`(회색) |
| 테이블 `압력 방향` | 최근 N봉(`압력/추진 비교 봉 수`, 기본 5) 매수 합 : 매도 합 비율. 임계 k(`중립/보통 비율 임계 k`, 기본 1.2) 초과면 `매수 (x.x : 1.0)`(녹)/`매도 (1.0 : x.x)`(빨강), 아니면 `중립` |
| 테이블 `평균선(SMA)` | 최근 N봉 평균 거래량 ÷ 20봉 평균. k 초과=`상회`(녹), 1/k 미만=`하회`(회색 — 매도로 오독하지 않도록 빨강 미사용), 그 사이=`보통` |

**매매에 쓰는 법** — 다른 지표의 신호 봉에 **힘이 실렸는지 확인**하는 용도입니다. 돌파·전환 신호 + `롱 유리`/`숏 유리` + 비정상(라임/빨강) 막대가 겹치면 추진력이 있는 것으로, 평균선 아래 `중립`에서 나온 신호는 힘이 약한 것으로 봅니다.

**주의** — 매수/매도 몫은 체결 데이터가 아니라 **종가 위치 기반 추정치**입니다. 형성 중 봉은 거래량·종가가 계속 바뀌므로 마감 후 값을 씁니다.

### 1-4. Triple-Stochastic-Wave (삼중 스토캐스틱)

**무엇을 보여주나** — 기간이 다른 스토캐스틱 3개(Fast 5/3/3 · Mid 10/6/6 · Slow 20/9/9)의 **순서(서열)** 로 단기 파동 방향을 보여줍니다. 소스: [`triple-stochastic-wave.pine`](./pinescript/TRIPLE-STOCH/triple-stochastic-wave.pine)

**차트에서 읽는 법**

| 요소 | 의미 |
| --- | --- |
| 선 3개 | Slow=파랑(굵게) · Mid=청록 · Fast=주황. `Basis`(기본 `K선`)로 %K 또는 %D 중 한 종류만 표시. **같은 `Basis`가 배경 서열·테이블 계산도 결정** |
| 계산 | 표준 스토캐스틱 `raw_k = 100 × (종가 − N봉 최저가) / max(N봉 범위, mintick)`, `%K = SMA(raw_k, K)`, `%D = SMA(%K, D)` — `max(…, mintick)`으로 0 나누기 방지 |
| 녹색 배경 | **정배열** Fast > Mid > Slow(엄격 부등호) — 빠른 선부터 위로 정렬, 상승 파동 |
| 빨간 배경 | **역배열** Fast < Mid < Slow — 하락 파동 |
| 수평선 | 80 과매수 · 50 중간선 · 20 과매도 |
| 우측 상단 테이블 | 헤더 없는 3행 `정배열`(녹 `#2E7D32`)/`중립`(검정)/`역배열`(적 `#C62828`) — 각 서열이 되는 가장 가까운 종가의 기준 종가 대비 %(틱 반올림·소수 1자리·부호). 이미 그 서열이면 `▶ 현재`(굵게, 기준봉이 확정봉이면 `(확정)`), 한 봉으로 불가능하면 `1봉 내 불가`(D선 기준에서 흔함). 현재가 정/역배열이면 `중립` 행이 이탈 임계. 닫힌형(구간별 선형) 해. `Table Base Bar`: `실시간봉`(기본, 현재 봉 종가 조건·틱마다 갱신) / `완성봉`(가장 최근 완성봉 기준 다음 봉 조건·고정) |
| 알림 | `Triple Stochastic Bull/Bear Alignment` — 세 스토캐스틱 각각 %K가 자기 %D 위/아래로 같은 방향 |

**매매에 쓰는 법** — 큰 방향(Auto VWAP 추세 확인)과 **같은 방향의 배경이 켜질 때**를 타이밍으로 씁니다. 상승 추세 중 과매도권(20 부근)에서 녹색 배경으로 바뀌면 눌림 매수 후보, 하락 추세 중 과매수권(80 부근)에서 빨간 배경이면 반등 매도 후보입니다.

**주의** — 빠른 오실레이터라 횡보장에서 배경이 자주 뒤바뀝니다(휩쏘). 형성 중 봉에서는 배경이 바뀌었다 돌아올 수 있으니 마감봉으로 확인합니다. 테이블 %는 매매 신호가 아니라 참고 조건입니다. `request.security`·`lookahead`를 쓰지 않아 미래참조는 없습니다.

> 이전의 Fast 골든/데드 크로스 원 마커와 구 우측 상단 상태 테이블은 제거되었습니다(CEO 지시). 현재 테이블은 서열 전환 가격 테이블 하나입니다.

### 1-5. cRSI (RSI Cyclic Smoothed)

**무엇을 보여주나** — 시장의 지배 사이클(기본 `Dominant Cycle Length = 20` → RSI 길이 10·사이클 메모리 40봉)로 평활한 RSI와, 최근 사이클 동안 cRSI가 실제로 머문 범위로 그린 **동적 과매수/과매도 밴드**입니다. 고정 30/70 대신 "지금 국면 기준으로 과한지"를 봅니다. 소스: [`rsi-cyclic-smoothed.pine`](./pinescript/cRSI/rsi-cyclic-smoothed.pine)

**차트에서 읽는 법**

| 요소 | 의미 |
| --- | --- |
| 골드 선 | cRSI 본선 |
| 시안 선 2개 | 상단 밴드(동적 과매수) · 하단 밴드(동적 과매도) — 사이클 메모리 구간에서 cRSI 분포의 상·하위 10% 경계. 우측 가격축에 값 표시 |
| 회색 점선 | 고정 참고 레벨 30 / 70 |
| 진한 주황 배경 | 밴드폭 ≤ 20 — 사이클 진폭 **수축** |
| 보라 배경 | 밴드폭 ≥ 35 — 진폭 **확장** |
| ▲ / ▼ 삼각형 | 확장(보라) 구간에서만 표시되는 상승(녹)/하락(빨강) **다이버전스** |
| 우측 상단 테이블 | `상단 돌파`/`상단 이탈`/`하단 돌파`/`하단 이탈` — 다음 봉 종가가 기준 종가 대비 몇 % 움직이면 cRSI가 밴드를 넘는지(틱 반올림·소수 1자리·부호, 크기 상한 없음). 현재 상태에 해당하는 행만 값, 나머지·해 없음은 `-`(어두운 톤). 행 배경: 돌파=녹 `#2E7D32`·이탈=적 `#C62828`. 돌파 행이 `−%`·이탈 행이 `+%`면 값이 **노랑 굵게** — 보합이나 역방향 소폭 움직임에도 다음 봉에 교차한다는 뜻. `테이블 기준봉`: `실시간봉`(기본, 틱마다 갱신·봉 마감 값은 완성봉과 동일) / `완성봉`(가장 최근 완성봉 기준, 형성 중 고정) |

**매매에 쓰는 법** — 하단 밴드 아래에서 밴드 안으로 복귀하면 과매도 해소(되돌림 롱 확인), 상단 밴드 위에서 복귀하면 과열 해소(되돌림 숏 확인)로 씁니다. 추세 구간에서는 상단 밴드 돌파 유지가 추세 강도 확인이 됩니다. 확장 구간 다이버전스는 반전 경고로 다른 지표와 함께 봅니다.

**주의** — 다이버전스 삼각형은 피벗 확인(오른쪽 5봉) 후에 **5봉 과거 위치에 찍히므로 실시간보다 늦게 나타납니다.** 밴드 교차 테이블은 매매 신호가 아닌 조건 %이며, 매매 근거로 쓸 때는 `완성봉` 기준으로 봅니다.

> 구 cRSI 상태판(`포지션`·`cRSI 값`·`모멘텀`)과 수축 구간 골든/데드 크로스 원 마커는 제거되었습니다(CEO 지시). 원작: Lars von Thienen, *Decoding The Hidden Market Rhythm*(2017) Ch.4 (CC BY 4.0).

| **단일 신호 불신** | 신호 하나를 믿지 않는다 — 여러 지표와 테이블이 한 방향으로 정렬됐는지 교차 검증한다 |
| **자본 보존 우선** | 얼마 벌지보다 얼마 잃을지를 먼저 정한다. 살아남으면 기회는 다시 온다 |
| **국면 규정** | 추세/횡보/역추세 중 지금이 어느 국면인지 먼저 규정하고, 국면에 맞는 방식으로만 매매한다 |
| **R:R 미확보 진입 배제** | 손익비(R:R)가 확보되지 않은 자리엔 진입하지 않는다 |
| **비대칭 베팅** | 확신이 아니라 확률로 베팅한다. 틀리면 작게 잃고 맞으면 크게 먹는다 — 그 비대칭이 전부다 |
| **기다림도 매매** | 자리가 아니면 관망이 최선의 포지션이다. 시장이 시나리오를 부정하면 시장이 아니라 나를 의심하고 물러난다 |

## 3. Claude Code ↔ TradingView MCP 연결

Claude Code가 TradingView 데이터를 읽게 하는 MCP는 **두 종류**이며 용도가 다릅니다. 시장 데이터 조회는 공식 MCP, **지금 데스크탑에 열린 차트**(지표 값·테이블·스크린샷)를 읽으려면 Desktop MCP가 필요합니다.

| 구분 | 공식 TradingView MCP | TradingView Desktop MCP |
| --- | --- | --- |
| 이름 | `mcp-tradingview` | `tradingview-desktop` (커뮤니티·비공식) |
| 할 수 있는 것 | 시장 데이터·스크리너·기술적 분석·뉴스·관심종목·알림 | 실행 중인 데스크탑 앱의 차트 상태·탭·지표 값·테이블·스크린샷·Pine Script 편집/컴파일 |
| 열린 차트 읽기 | **불가** | 가능 |
| 연결 방식 | 원격 URL + TradingView OAuth | 로컬 디버그 연결 (맥) |
| 요구 사항 | TradingView Essential 이상 유료 플랜(체험판 불가), API Key 불필요 | Node.js 20.19 이상 |

### 3-1. 공식 TradingView MCP

```bash
claude mcp add --transport http --scope user mcp-tradingview https://mcp.tradingview.com/mcp
```

1. `claude` 실행 → `/mcp` → `mcp-tradingview` 선택 → **Authenticate**
2. 브라우저에서 TradingView 로그인 → 권한 승인
3. 확인: `claude mcp list` 또는 Claude Code 안에서 `/mcp`

### 3-2. TradingView Desktop MCP

```bash
node -v                                              # 20.19 이상인지 확인
npx -y tradingview-desktop-mcp launch --restart      # 현재 레이아웃을 저장한 뒤 실행 — 디버그 모드로 앱 재시작
claude mcp add --scope user tradingview-desktop -- npx -y tradingview-desktop-mcp
npx -y tradingview-desktop-mcp doctor                # 차트 탭이 활성인 상태에서 점검
```

등록 후 **Claude Code를 재실행**하면 사용할 수 있습니다.

> ⚠️ 비공식 프로젝트라 TradingView 앱 업데이트에 따라 동작이 달라질 수 있습니다. 로컬 디버깅 포트는 외부(네트워크·포트포워딩)에 **노출하지 마세요.**

**예시 프롬프트**

```text
현재 열린 차트의 종목·타임프레임·지표를 읽고 분석해줘. 차트는 수정하지 마.
```

차트를 바꿀 수 있는 도구(지표 추가·삭제, 입력값 변경, 종목·타임프레임 변경 등)도 포함되어 있으므로, 분석만 원할 때는 위처럼 **"수정하지 마"를 명시**합니다.
