# KJH-Trading

CEO 매매 차트(**CME_MINI:NQ1! 일봉**)에 올린 지표의 사용 설명서입니다.
메인 지표는 **4종 — Auto VWAP · Triple-Stochastic-Wave · cRSI · Volume-Pressure-Tracker** 이고, **VRVP**(TradingView 내장)는 가격대별 거래량을 보는 참고용입니다.

핵심 원칙은 하나입니다. **신호 하나를 믿지 않는다.** 네 지표가 같은 방향을 가리키는지 함께 봅니다.

## 1. 지표 가이드

지표마다 `무엇을 재나 → 차트에서 읽는 법 → 핵심 숫자 → 잘 맞는 국면 → 흔한 실수` 순서입니다. 숫자는 모두 소스 기본값입니다.

> **공통 주의 3가지**
> 1. 어느 지표도 단독 진입 근거가 아닙니다.
> 2. 판단은 **마감된 봉** 기준으로 합니다. 형성 중인 봉의 값·색·마커는 틱마다 바뀌고 사라질 수도 있습니다.
> 3. 테이블의 "가격"·"%"는 "이 종가로 마감하면 상태가 바뀐다"는 **조건**입니다. 예측이 아닙니다.

### 1-1. Auto VWAP

**무엇을 재나** — 최근 20봉 동안 거래된 물량의 평균 단가(VWAP)를 기준으로, 지금 가격이 평소보다 얼마나 멀리 나왔는지와 이동평균들이 어느 방향으로 정렬됐는지를 봅니다. 비유하면 "최근 참가자들의 평균 매입가와, 그 평균에서 벗어난 거리".

**차트에서 읽는 법**
- **점선 밴드 2쌍** — 흰 대시 = 최근 20봉 VWAP의 ±2σ, 회색 점 = 최근 50봉 VWAP의 ±2σ. σ는 기본값에서 로그 가격의 거래량 가중 표준편차이며, 밴드는 `VWAP × e^(±2σ)`입니다. VWAP 중앙선은 기본으로 숨겨져 있습니다.
- **리본 3선** (종가 기준, 길이 20) — EMA 노랑 · DEMA 하늘 · TEMA 분홍. TEMA가 가장 빠르고 EMA가 가장 느립니다.
- **거래량 가중선** — 50선 주황 · 100선 파랑 · 200선 보라 (VWMA, 종가 기준).
- **배경색 (Sonar 모멘텀)** — Sonar = EMA20 − 9봉 전 EMA20, Signal = Sonar의 EMA9. Sonar가 Signal 위 = 골든, 아래 = 데드. 골든이면서 상승 밴드워킹이면 파랑, 그 밖의 골든은 녹색, 데드이면서 하락 밴드워킹이면 빨강, 그 밖의 데드는 주황입니다.
- **캔들 색 덮어쓰기** — 붉은 캔들 = 과매수 극단, 파랑 캔들 = 과매도 극단(아래 "핵심 숫자" 참고).
- **원 마커** — 하늘색 원(봉 아래) / 분홍 원(봉 위) = Williams %R(20) 1봉 다이버전스.
- **우측 상단 상태 테이블** — 아래 표 참고.

**핵심 숫자** — VWAP 20봉(소스 hlc3), 밴드 ±2σ(로그), 세트 B 50봉, 리본 20, VWMA 50/100/200, Sonar 20/9/9, %R 20(−80/−20). 극단 캔들 = cRSI(주기 20 기준) ≥ 70 이면서 고가가 볼린저(20, 2σ) 상단을 캔들 길이의 30% 이상 넘은 봉. 이 색은 그 봉 하나로 끝나지 않고, 이격도(종가 ÷ SMA20)가 중립으로 돌아올 때까지 다음 봉들도 같은 색으로 칠합니다. 과매도(파랑)는 대칭(≤ 30, 하단 이탈).

**Williams %R 원 마커** — %R 라인은 눈금(−100~0)이 가격과 달라 가격 차트에 그리지 않고, 다이버전스가 난 봉에만 원을 찍습니다. %R(20)은 종가가 최근 20봉 고저 범위의 어디에 있는지를 −100(최저)~0(최고)으로 나타냅니다. 판정은 직전 봉과 이번 봉 **1봉 비교**입니다(피벗 기반 아님).

| 원 | 위치 · 기본색 | 조건 (모두 충족) | 읽는 법 |
| --- | --- | --- | --- |
| 하늘색 원 | 봉 아래 · `#81D4FA` | 직전 봉 %R < −80, 이번 봉 종가 < 직전 종가, 이번 봉 %R > 직전 %R | 과매도 구간에서 종가는 내렸는데 %R은 올랐다 = **저가 거부**. 하락 힘이 약해지는 징후 |
| 분홍 원 | 봉 위 · `#FF1493` | 직전 봉 %R > −20, 이번 봉 종가 > 직전 종가, 이번 봉 %R < 직전 %R | 과매수 구간에서 종가는 올랐는데 %R은 내렸다 = **고가 거부**. 상승 힘이 약해지는 징후 |

- **리페인팅**: 이번 봉 종가와 %R로 판정하므로 형성 중인 봉에서는 원이 켜졌다 꺼질 수 있습니다. 봉이 마감되면 확정되며, 미래 데이터는 쓰지 않습니다. **마감봉의 원만** 인정합니다.
- **2절에서 쓰는 법**: 원은 **단독 진입 신호가 아닙니다.** 이격도와 같은 "20봉 위치" 정보라 절대 기준의 **④ 변동성 축**에 들어갑니다. 전략 A에서는 **필수**(A2: 롱 = 최근 3봉 내 하늘색 원, 숏 = 분홍 원), 전략 B·C에서는 **최근 5봉 내 반대 방향 원 = 변동성 불리(금지)**(롱이면 분홍 원), 전략 B에서는 **같은 방향 원 = 역행 경험(B2) 인정**입니다([2-2](#2-2-판정-위계와-상태-점수판) · [2-7](#2-7-전략-a--역추세) · [2-8](#2-8-전략-b--추세-예측) · [2-9](#2-9-전략-c--추세-확정)). 1봉 비교라 노이즈가 많고, 연속으로 찍히면 1회로 셉니다.
- **설정**: `윌리엄스 %R 다이버전스` 그룹 — `%R 다이버전스 원 표시`(기본 ON), `윌리엄스 %R 길이`(20), `%R 하단 밴드`(−80), `%R 상단 밴드`(−20), 원 색 2개.

**상태 테이블 — 섹션별 핵심** (기본 레이아웃 가로형, 세로형 선택 가능. 섹션 제목 괄호 = 기준봉)

| 섹션 (기본 기준봉) | 이 섹션이 답하는 질문 | 핵심 행 |
| --- | --- | --- |
| ① 추세 확인 (완성봉) | 이동평균 기준으로 추세가 이미 정해졌나? (후행) | `단기추세` VWMA20(차트에 안 그림) vs 50 · `중기추세` 50 vs 100 · `장기추세` 100 vs 200. 값: `골든/데드 크로스`, `(강한/약한) 상승·하락 (+x.x% \| N봉)` |
| ② 기울기 전환가 (실시간봉) | 다음 봉이 얼마에 마감하면 리본선이 꺾이나? | `TEMA 전환` · `DEMA 전환` · `EMA 전환` |
| ③ 교차 전환가 (실시간봉) | 다음 봉이 얼마에 마감하면 두 선이 교차하나? | `Sonar 교차`(배경색 방향 반전) · `T/D 교차`(TEMA와 DEMA 교차) |
| ④ 변동성 임계가 (실시간봉) | 밴드를 타고 달리는 중인가, 평균에서 너무 멀어졌나? | `상승확장(20)` · `하락확장(20)` · `상승확장(50)` · `하락확장(50)` · `이격도` |
| ⑤ 지지·저항 임계가 (완성봉) | 50/100/200선이 지금 지지인가 저항인가? | `50선` · `100선` · `200선` (값 = 선 가격과 종가 대비 %) |

- **색**: 청록 = 상승 쪽, 자홍 = 하락 쪽, 회색 = 중립·데이터 부족. ⑤만 녹 = 지지, 빨강 = 저항, 흐린 녹/흐린 빨강 = 판정 없이 선 위/아래.
- **① 강약**: 크로스 후 5봉 동안은 `상승`/`하락`만 표시합니다. 그 뒤 두 선 간격이 5봉 전보다 ATR14 × 0.25 넘게 벌어지면 `강한`, 그만큼 좁아지거나 간격이 종가의 4% 이하이면 `약한`입니다. 간격이 4% 이하여도 벌어지는 중이면 `강한`입니다.
- **② 세 행은 정의가 같습니다.** 각 선(TEMA·DEMA·EMA)의 **1봉 기울기 부호가 바뀌는(선이 꺾이는) 다음 봉 종가**입니다. 청록 = 그 선이 오르는 중(값은 `하락전환` 가격), 자홍 = 내리는 중(값은 `상승전환` 가격)입니다. 셋이 같은 색이면 리본 기울기가 한 방향으로 모인 상태입니다. `EMA 전환`이 가장 늦게 바뀌는 것은 리본 순서가 기울기 방향과 같을 때(상승 중 DEMA > EMA, 하락 중 DEMA < EMA)뿐이고, 반대 구조인 반등·반락 초기에는 EMA 전환가가 가장 가까울 수 있습니다. `EMA 전환` 가격은 지금 EMA(노랑 선) 값과 같습니다. 종가가 EMA 위에서 마감하면 EMA가 오르고, 아래에서 마감하면 내리기 때문입니다. (2026-11-05 변경: 구 `정배열 전환`·`역배열 전환` 행 삭제, `EMA 전환` 행 추가)
- **②③④의 가격** (실시간봉 모드): 지금 형성 중인 봉을 고정으로 보고 **다음 봉 종가**가 그 가격이면 상태가 바뀐다는 뜻입니다. 기준가 대비 ±50%를 넘으면 `도달불가`로 표시합니다.
- **④ 밴드워킹**: 종가가 20봉 VWAP의 +1σ 위이고 VWAP의 5봉 기울기가 상승이면(기울기가 평탄하면 밴드폭 확장 중일 때) 상승 워킹입니다. 하락은 대칭입니다. +2σ 위에 있더라도 밴드가 넓어지지 않고 VWAP가 평탄·하락이면 워킹에서 뺍니다. 확장 행의 가격은 수치 탐색으로 구한 근사값이며, 다음 봉 거래량은 기준봉과 같다고 가정합니다. 값은 `가격 (±x.x% | N봉)` 형식이고(예: `하락확장(20)`에 `횡보 : 13,000 (+2.0% | 2봉)` = 하락 워킹 2봉째), `N봉`은 현재 국면(상승 워킹 / 하락 워킹 / 횡보)이 이어진 봉 수로 국면이 바뀌면 1부터 다시 셉니다(같은 기간 두 행 공통, 실시간봉 모드면 형성 중인 봉 포함). `상승확장(50)`·`하락확장(50)`은 같은 판정식을 50봉 VWAP·밴드로 적용한 행이며, 20 쌍과 국면·N을 따로 셉니다.
- **④ 이격도**: 값은 `{20 기준} | {50 기준} ({판정})`입니다(예: `96.6 | 95.6 (되돌림 주의)`). 20 기준 = 종가 ÷ SMA20 × 100, 50 기준 = 종가 ÷ SMA50 × 100, 괄호 = 20 기준 판정. 판정 기준은 고정 ±10%와 최근 50봉 이격도 표준편차 × 1.5 두 가지이며 20 기준에만 적용합니다. 하나를 넘으면 `되돌림 주의`, 둘 다 넘으면 `되돌림 확실`이고, 셀 색도 20 기준입니다.

**잘 맞는 국면 / 약한 국면** — 추세 구간에서는 리본·VWMA 정렬과 밴드워킹이 방향을 잘 요약합니다. 횡보 구간에서는 리본 기울기와 Sonar가 자주 뒤집혀 테이블 값이 계속 바뀝니다(휩쏘). 이 성향은 일반론이며, 펀드 데이터로 검증하지 않았습니다.

**초보가 흔히 하는 실수**
- 녹색 배경을 "상승 추세"로 읽는 것. Sonar 골든은 "9봉 모멘텀이 자기 평균보다 좋아졌다"는 뜻이라, 하락이 둔화되기만 해도 켜집니다.
- 실시간봉 값(②③④, 배경색, 원 마커, 캔들색)으로 바로 판단하는 것. 형성 중에는 켜졌다 꺼질 수 있으니 마감 후에 확인합니다.

### 1-2. Triple-Stochastic-Wave (삼중 스토캐스틱)

**무엇을 재나** — 기간이 다른 스토캐스틱 3개가 "최근 고저 범위 안에서 종가가 어디쯤인가"(0~100)를 각각 잽니다. 짧은 기간 값이 긴 기간 값보다 위에 있으면 단기 흐름이 더 강하다는 뜻입니다. 비유하면 단거리·중거리·장거리 선수의 순위표.

**차트에서 읽는 법**
- **선 3개** — Fast 주황 · Mid 청록 · Slow 파랑(굵게). `Basis` 설정(기본 `K선`)에 따라 %K 또는 %D 한 종류만 그립니다.
- **녹색 배경 = 정배열** (Fast > Mid > Slow), **빨간 배경 = 역배열** (Fast < Mid < Slow). 나머지 순서는 배경이 없습니다(중립).
- **수평선** — 80 / 50 / 20.
- **우측 상단 테이블** (3행 `정배열`·`중립`·`역배열`) — 각 순서가 되려면 종가가 기준 종가 대비 몇 % 움직여야 하는지 보여줍니다. 이미 그 상태인 행은 라벨 앞에 `▶`, 값은 `현재`입니다. 한 봉 종가로 만들 수 없으면 `1봉 내 불가`입니다. 기본 `실시간봉` 모드는 **지금 형성 중인 봉**의 종가 조건입니다(Auto VWAP·cRSI 테이블의 "다음 봉"과 다릅니다).

**핵심 숫자** — Fast 5/3/3 · Mid 10/6/6 · Slow 20/9/9 (기간/%K 평활/%D 평활). `raw = 100 × (종가 − N봉 최저) / (N봉 최고 − N봉 최저)`, `%K = SMA(raw)`, `%D = SMA(%K)`. 알림 2종은 세 스토캐스틱 각각의 %K가 자기 %D 위(또는 아래)에 있을 때입니다. 배경의 순서 판정과는 다른 조건입니다.

**잘 맞는 국면 / 약한 국면** — 방향이 있는 구간의 눌림·반등 타이밍을 볼 때 잘 맞습니다. 횡보에서는 배경이 자주 바뀌고, 강한 추세에서는 80 위나 20 아래에 오래 머뭅니다(일반론, 펀드 데이터 미검증).

**초보가 흔히 하는 실수**
- 80 위를 곧바로 "매도", 20 아래를 "매수"로 읽는 것. 강한 추세에서는 극단 구간이 오래 갑니다.
- 정배열을 "상승 추세"로 읽는 것. 정배열은 최근 5~20봉 범위 안의 상대 위치일 뿐이며 큰 추세는 Auto VWAP ①로 봅니다.

### 1-3. cRSI (RSI Cyclic Smoothed)

**무엇을 재나** — RSI를 시장 사이클 길이에 맞춰 평활한 선(cRSI)과, 최근 40봉 동안 그 선이 실제로 움직인 범위로 만든 **동적 과열/침체 밴드**입니다. 고정 30/70 대신 "요즘 기준으로 높은가 낮은가"를 봅니다.

**차트에서 읽는 법**
- **골드 선** = cRSI. **시안 선 2개** = 상단 밴드(최근 40봉 cRSI 값의 상위 약 10% 경계) / 하단 밴드(하위 약 10% 경계).
- **회색 점선** = 고정 참고선 30 / 70.
- **배경** — 진한 주황 = 밴드폭(상단 − 하단) ≤ 20, 진폭 수축. 보라 = 밴드폭 ≥ 35, 진폭 확장. 단위는 cRSI 점수(0~100)입니다.
- **▲ / ▼** = 상승/하락 다이버전스. 보라(확장) 배경일 때만 그립니다.
- **우측 상단 테이블** (`상단 돌파`·`상단 이탈`·`하단 돌파`·`하단 이탈`) — 다음 봉 종가가 기준 종가 대비 몇 %이면 cRSI가 밴드를 넘는지 보여줍니다. 지금 상태에 해당하는 행만 값이 나오고 나머지는 `-`입니다. 값이 **노랑 굵게**이면 보합이나 반대 방향 소폭 움직임으로도 다음 봉에 교차한다는 뜻입니다.

**핵심 숫자** — Dominant Cycle 20 → RSI 길이 10, 위상 지연 4봉, 평활 계수 2/11, 밴드 계산 구간 40봉, 밴드 경계 10%. 식: `cRSI = (2/11) × (2·RSI − RSI[4봉 전]) + (9/11) × 직전 cRSI`. 수축/확장 기준 20 / 35.

**잘 맞는 국면 / 약한 국면** — 사이클이 비교적 규칙적인 박스·완만한 추세에서 밴드 이탈과 복귀가 의미 있게 나옵니다. 강한 추세에서는 밴드도 따라 움직여 한쪽 밴드 근처에 붙어 있을 수 있습니다(일반론, 펀드 데이터 미검증).

**초보가 흔히 하는 실수**
- 다이버전스 삼각형을 실시간 신호로 쓰는 것. 피벗은 오른쪽 5봉이 지나야 확인되므로 **5봉 늦게, 5봉 과거 위치에** 찍힙니다. 보라 배경 조건도 삼각형 위치가 아니라 확인 시점의 봉에서 봅니다.
- 하단 밴드 아래를 곧바로 "바닥"으로 읽는 것. 밴드는 최근 40봉 분포일 뿐이라 하락 추세에서는 함께 내려갑니다.

### 1-4. Volume-Pressure-Tracker (거래량 압력)

**무엇을 재나** — 봉마다 거래량을 종가 위치로 매수 몫과 매도 몫으로 나눠 **추정**하고, 거래량이 평소보다 큰지 봅니다. 실제 체결(호가) 데이터가 아니라 "종가가 고가 쪽이면 매수 몫이 크다"는 근사입니다.

**차트에서 읽는 법**
- **막대** — 전체 거래량(매도색) 위에 매수 몫(매수색)을 겹쳐 그립니다. 매수 몫 = `거래량 × (종가 − 저가) / (고가 − 저가)`. 고가 = 저가인 봉은 반씩 나눕니다.
- **막대 색** — 평소: 매수 흰색 · 매도 회색. 거래량이 20봉 평균의 2배를 넘는 봉: 매수 라임 · 매도 빨강.
- **주황 선** = 거래량 20봉 평균.
- **테이블 3행** — `거래량 압력`: 이번 봉 거래량이 20봉 평균보다 크고 종가가 봉 중간값((고가+저가)/2)보다 위면 `롱 유리`, 아래면 `숏 유리`. 거래량이 평균 이하이거나, 종가가 정확히 중간값이거나, 고가 = 저가면 `중립`. `압력 방향`: 최근 5봉 매수 합 ÷ 매도 합이 1.2배를 넘으면 `매수`, 반대로 1.2배를 넘으면 `매도`, 그 사이는 `중립`. `평균선(SMA)`: 최근 5봉 평균 ÷ 20봉 평균이 1.2 초과면 `상회`, 1/1.2(약 0.83) 미만이면 `하회`(회색), 그 사이는 `보통`.

**핵심 숫자** — 비교 20봉, 비정상 배수 1.0(= 평균의 2배 초과), 평균선 20, 비교 봉 수 N = 5, 임계 k = 1.2. 평균에 현재 봉도 들어가므로 "2배 초과"는 직전 19봉 평균 대비로는 약 2.11배 초과입니다. `압력 방향`의 1.2배는 매수 몫이 약 54.5%를 넘는다는 뜻입니다.

**잘 맞는 국면 / 약한 국면** — 돌파나 급변 봉에 거래량이 실렸는지 확인할 때 유용합니다. 꼬리가 긴 봉, 갭, 장중 왕복이 큰 봉에서는 종가 위치 추정이 실제 매수·매도와 크게 다를 수 있습니다(일반론, 펀드 데이터 미검증).

**초보가 흔히 하는 실수**
- 장중에 `중립`을 "힘이 없다"로 읽는 것. 형성 중인 봉은 거래량이 아직 덜 쌓여 평균보다 작게 나오기 쉽습니다. 마감 후에 봅니다.
- 라임/빨강 막대를 매수/매도 신호로 쓰는 것. 큰 거래량은 추세 시작에도, 추세 끝(투매·과열)에도 나옵니다.

### 1-5. VRVP (참고용, TradingView 내장)

화면에 보이는 구간의 거래량을 **가격대별 가로 막대**로 쌓아 거래가 몰린 가격(매물대)을 보여줍니다. POC = 거래량이 가장 많은 가격, VAH/VAL = 거래량 70%가 몰린 범위의 위/아래 끝(현재 차트 설정). 화면을 스크롤·확대하면 계산 구간이 바뀌어 **POC도 바뀝니다**. 레벨을 기록할 때는 어느 구간 기준인지 함께 남깁니다. 연속 선물(NQ1!)은 롤오버 구간 거래량이 섞입니다. 메인 지표가 아니므로 판단 근거가 아니라 레벨 참고용으로만 씁니다.

### 1-6. 메인 4종 함께 보는 법

| 지표 | 맡은 질문 |
| --- | --- |
| Auto VWAP | **추세와 위치** — 큰 방향은 어디이고, 가격이 평균에서 얼마나 떨어져 있나 |
| Triple-Stochastic-Wave | **모멘텀 타이밍** — 단기 흐름이 지금 같은 방향으로 정렬됐나 |
| cRSI | **과열과 사이클** — 최근 기준으로 너무 올랐거나 내렸나 |
| Volume-Pressure-Tracker | **거래량 확인** — 움직임에 거래량이 실렸나 |

- **정렬**: 네 지표가 같은 쪽을 가리키면(예: VWAP 추세 상승 + 스토캐스틱 정배열 + cRSI 과열 아님 + 거래량 평균 위) 상태가 한 방향으로 모였다고 읽습니다.
- **충돌**: 서로 다른 쪽을 가리키면 국면이 불분명하다는 정보로 읽습니다. 어느 한 지표를 골라 믿지 않습니다.
- **역할이 다른 정보만 셉니다.** 스토캐스틱과 cRSI는 둘 다 가격에서 나온 오실레이터라 겹치는 정보가 많습니다. 두 개가 같은 방향이라고 근거가 두 배가 되지는 않습니다.
- **주의: 이 조합이 수익(엣지)을 낸다는 것은 아직 검증되지 않았습니다.** 위 내용은 읽는 순서일 뿐 진입·청산 규칙이 아닙니다. 규칙은 [2. 매매 전략 (가설)](#2-매매-전략-가설)에 있으며, 그 역시 거래비용을 넣은 표본 외 검증과 CEO 승인 전에는 실매매 규칙이 아닙니다.

> **경고 — 모든 진입 규칙과 승률·R:R 수치는 백테스트되지 않은 가설·가정이며, 검증 전에는 실매매 규칙으로 쓰지 않는다.**
> - 펀드 데이터로 엣지(기댓값 > 0)가 확인된 규칙은 아직 하나도 없습니다. 이번 판정 위계 재설계(2026-11, CEO 결정·알고리즘 수학자 설계)도 **전체가 백테스트되지 않은 가설**입니다.
> - 수학자 의견: ①을 보조 기준으로 내리면 숏이 열리지만, NQ의 양(+) 드리프트가 숏에 거래당 약 0.1~0.25R의 역풍을 줍니다(방향·드리프트 미검증).
> - 절대 기준 5축은 독립 정보 5개가 아닙니다(실질 약 4개, [2-2](#2-2-판정-위계와-상태-점수판) 정보원 중복 참고).

알고리즘 수학자가 설계하고 본부장이 검수한 실전 데이·스윙 참고서입니다. 기준은 메인 4종 소스 기본값이며, 기본 운용은 NQ1! 일봉 스윙입니다(데이 모드는 [2-4](#2-4-운용-모드-데이--스윙)).

**판정 위계 한 줄 요약** — 진입 자격은 **절대 기준 5축**(지지/저항 · 변동성 · 교차 · 기울기 · 거래량)으로만 정합니다. **보조지표 2종**(cRSI · 삼중 스토캐스틱)은 비중 배수와 진입 방식을, **보조 기준**(Auto VWAP ① 추세 확인)은 비중 배수·보유기간·목표 크기를 정합니다. 보조지표와 ①은 진입을 금지하는 게이트가 아닙니다.

- **A 역추세** — 20봉 위치 극단(④ 이격도 + %R 원)에서 평균 쪽 되돌림을 짧게 먹습니다.
- **B 추세 예측** — 되돌림이 끝나 지지(롱)/저항(숏)이 형성되고 ③ 교차가 먼저 돌아선 지점에서 들어갑니다.
- **C 추세 확정** — B의 조건에 ② 기울기 전환, ③ T/D 확정, 거래량 확인까지 더해진 뒤 눌림 저점(반등 고점)에서 추세 방향으로 들어갑니다.
- 증액은 **B → C만** 허용합니다.

**전략 정의**

- **CEO 정의(2026-11-04 확정)**
  - **A 역추세**: 과매도 구간에서 롱, 과매수 구간에서 숏

  - **C 추세 확정**: 추세 추종. 추세가 확인됐을 때 예상된 눌림에서 진입

| 하락 추세 | **A 롱** (추세 반대, 축소 비중: 판정 TF ① 역행이면 ×0.5 상한·T1 전량) (2026-11-06, 문구 정합화) | **C 숏** (반등 지정가) | **A 숏** (① 셋 다 `약한 하락` + 200선 아래 한정, ×0.75 · 기준 사례) / C 반등 지정가가 이미 걸려 있으면 유지 |

> 주석: 국면(상승/비추세/하락)과 위치(과매도/중립/과매수)를 어떤 지표·셀·값으로 판정할지는 **CEO 지시 대기**다. 아래 하위 절의 지표 기준은 아직 이 정의에 맞춰 정합화하지 않은 상태다. 2-7 A의 기준 사례(NQ 일봉 29,117.75, 8월 저점)는 ① `약한 상승` 국면의 과매도를 A 롱으로 본다 **(CEO 기준 사례, 표본 2건, 미검증)**.

> 추세 반대 A(상승 추세의 A 숏, 하락 추세의 A 롱)는 A3의 200선 조건 때문에 가격이 200선의 추세 쪽(숏: 200선 위, 롱: 200선 아래)에 있으면 성립하지 않는다. 이 경우 배정표 칸은 "배정 없음(200선 반대편)"으로 읽고, 리포트에는 역추세 행을 남기되 A3 0점 사유를 `200선 반대편(구조적)`으로 적는다. (2026-11-06, 트레이더 리뷰)

> 검토 후 기각(2026-11-06, 수학자): 200선까지 1 ATR 이상이면 200선 조건을 기록만 하는 완화(숏·롱 대칭) — 추세 반대 A는 판정 TF ① 역행이면 ① 배수가 ×0.5(2-7 상한)라 검증 변형 ×0.5를 곱하면 0.5% × 0.5 × 0.5 = 0.125% < 0.2%로, 역행이 아니어도 최대 ×0.75라 0.19% < 0.2%로 규칙상 진입이 생기지 않는다 (2026-11-06, 문구 정합화). 이 칸의 역추세 행 기록(A3 0점 `200선 반대편(구조적)`)을 n ≥ 30 모은 뒤 재검토한다.

> 예시는 모두 일봉 · 롱 포지션 기준이며, 숏은 롱 기준을 반대로 체크한다. 예시는 CEO 지정 기준 사례(미검증)이다.
> 예시 이미지 3장은 2026-11-05 새 테이블 구조로 다시 캡처한 **BTC/USD Coinbase 일봉 리플레이** 화면이다. **세 장 모두 지금 규칙으로는 진입 불가(금지 또는 필수 미충족) 장면**이며, 셀 읽는 법과 금지 조건을 보여 주는 판독 예시다. 진입 가능 장면의 예시나 성과 근거가 아니다(종목 1개, 수동 선택).

#### A 역추세 — 과매도에서 평균 쪽 되돌림

비추세 국면이 기본 무대이고, 추세 국면에서는 추세 반대 방향으로만 줄인 비중으로 쓴다. 20봉 위치 극단(④ 이격도 + %R 원)에서 평균 쪽 되돌림을 짧게 노린다. 원 봉 이후 3봉 안의 첫 상승 마감에서 진입한다. 규칙은 [2-7](#2-7-전략-a--역추세).

![A 역추세 예시 — BTC/USD Coinbase 일봉](./assets/%EC%97%AD%EC%B6%94%EC%84%B8%EC%98%88%EC%8B%9C.png)

**BTC/USD Coinbase 일봉(리플레이), 종가 62,791.00 — 진입 불가 사례** · 과매도 극단, A 롱 대기
- 직전 고점의 분홍 %R 원 → 긴 하락 → 급락. 하늘색 원은 급락 초기에 찍혔고, 마지막 봉은 파랑 캔들(과매도 극단)이다.
- ④ 이격도 `74.1 | 71.4 (되돌림 확실)`(녹, 아래쪽 극단 2단계) → A1 후보. `하락확장(20)` `횡보 : 69,366.35 (+10.5% | 8봉)`, `하락확장(50)` `횡보 : 75,264.45 (+19.9% | 8봉)` → 두 쌍 모두 하락 워킹 8봉째.
- ② `TEMA 전환`·`DEMA 전환`·`EMA 전환` 셋 다 자홍(`상승전환 : 76,287.61 (+21.5%)` · `78,888.62 (+25.6%)` · `82,090.16 (+30.7%)`). 세 선이 모두 내리는 중이고, 가장 가까운 TEMA 상승전환도 +21.5% 위다. ③ `Sonar 교차`·`T/D 교차`는 `도달불가`.
- ① 단기 `하락` · 중기 `강한 하락` · 장기 `하락` → 판정 TF ① 역행(A: 맥락 TF와 무관하게 ×0.5 상한, T1에서 전량) (2026-11-06, 문구 정합화). ⑤ 50·100·200선 모두 흐린 빨강(선 아래, +34.9% ~ +58.5%) → T1 후보는 SMA20 또는 ② TEMA 상승전환가.
- 거래량 `숏 유리` + `매도 (1.0 : 2.2)` + `상회 (2.0 : 1.0)`. cRSI `하단 돌파` 활성(복귀 전환가 +11.9%), 스토캐스틱 `▶ 중립 (확정)`.
- 주의: 이 화면 그대로는 **A 롱 금지**다. 하락 워킹 N ≥ 3봉, 거래량 불리(`숏 유리` + `매도` + `상회`), 최근 3봉 안 하늘색 원 없음(A2 미충족). 워킹이 풀리고, 새 하늘색 원 뒤 3봉 안에 첫 상승 마감이 나올 때까지 A 롱 필수 조건 미충족 상태다.

#### B 추세 예측 — 중립 구간에서 다음 방향을 먼저

추세가 확인되지 않은 국면에서, 과매도도 과매수도 아닌 중립 위치에서 다음 방향을 예측해 들어간다. 지지(L) 형성 + ③ 교차가 먼저 돌아선 것이 핵심이다. B1~B5가 처음 모두 성립한 마감봉에서 진입하고, 추세가 확인되면 C 기준으로만 증액한다. 규칙은 [2-8](#2-8-전략-b--추세-예측).

![B 추세 예측 예시 — BTC/USD Coinbase 일봉](./assets/%EC%B6%94%EC%84%B8%EC%98%88%EC%B8%A1%EC%98%88%EC%8B%9C.png)

**BTC/USD Coinbase 일봉(리플레이), 종가 68,853.61 — 진입 불가 사례** · 급락 뒤 바닥 다지기(횡보)
- 급락 뒤 저점 부근 하늘색 원(B2 역행 경험) → 그 저점(L) 위에서 횡보. ④ 확장 4행 모두 회색(횡보), 이격도 `100.5 | 100.3 (중립)` → 극단이 아닌 중립 위치.
- ③ `Sonar 교차` 청록(`하락교차 : 62,661.01 (-9.0%)`), `T/D 교차` 청록 원색(`데드교차 : 67,177.13 (-2.4%)`).
- ② `TEMA 전환`·`DEMA 전환`·`EMA 전환` 셋 다 청록(`하락전환` -1.3% · -1.2% · -0.6%). `EMA 전환` 68,445.25는 노랑 EMA 값이며 셋 중 가장 가깝다. 종가가 그 아래에서 마감하면 EMA부터 꺾인다.
- ⑤ `50선` 녹(지지, -0.1%), `100선`·`200선` 흐린 빨강(+9.1%, +25.6%).
- 스토캐스틱 `▶ 정배열 (확정)`, cRSI 밴드 안(`상단 돌파` +11.5% · `하단 이탈` -16.2% 활성).
- 주의: ① 단기 `데드 크로스` · 중기·장기 `하락` → 판정 TF ① 역행(청산 제한: 트레일 금지·시간 손절 5봉). ① 배수는 주봉 `장기추세`가 역행이면 ×0.5, 순행·약한 순행·`-`이면 ×0.75 (2026-11-06, 문구 정합화). 거래량 `숏 유리`(`압력 방향` `중립 (1.1 : 1.0)` · `평균선(SMA)` `하회 (0.8 : 1.0)`)는 형성 중인 봉 값일 수 있으니 마감 후 다시 본다. 마감 후에도 `숏 유리`면 거래량 불리로 B 금지다.

#### C 추세 확정 — 확인된 추세의 눌림에서

추세가 확인된 국면에서만 추세 방향으로 들어간다. B의 조건에 ② 기울기 전환, ③ T/D 확정, 거래량 확인까지 더해진 뒤 눌림 저점(L2)에서 진입한다. 신고가 추격은 하지 않는다. 규칙은 [2-9](#2-9-전략-c--추세-확정).

![C 추세 확정 예시 — BTC/USD Coinbase 일봉](./assets/%EC%B6%94%EC%84%B8%ED%99%95%EC%9D%B8%EC%98%88%EC%8B%9C.png)

- 저점 하늘색 원 → 눌림 저점(L2) → 상승 전환. ① `단기추세` `상승 (+0.6% | 1봉)`(골든 크로스 직후), 중기 `약한 하락` · 장기 `하락`.

### 2-0. 퀵 레퍼런스

판정 TF 봉이 마감될 때마다 이 순서로 봅니다. 앞 단계에서 패스가 나오면 그 전략은 거기서 멈춥니다.

```
0'. 분류     국면(상승 추세 / 비추세 / 하락 추세)과 위치(과매도 / 중립 / 과매수)를 먼저 정한다
             → 배정표로 방향별 전략이 하나로 정해진다(추세 방향 = C, 비추세 중립 = B, 극단의 평균 쪽 = A)
             (국면·위치를 판정할 셀과 값: CEO 지시 대기)
0. 준비      판정 TF 마감봉인가? 이벤트·롤 주간인가? 맥락 TF ①은?
1. 지지/저항  ⑤ 50·100·200 색 → 불리(빨강/롱) 있으면 A만 가능 여부 확인, B·C 패스
               기준 저점 L/L2 형성(2봉 미갱신) 되었나?
2. 변동성    ④ 확장 셀 → 반대 방향 워킹이면 전 전략 패스 (A는 워킹 N ≤ 2봉(50은 N ≤ 1봉)까지 예외)
               이격도 극단 + %R 원(3봉) → A 후보 / 워킹 해제 + 반대 극단·원 없음 → B·C 후보
3. 교차      ③ Sonar 청록 + T/D 자홍 원색 아님 → B 후보 / T/D 청록 원색 → C 후보
4. 기울기    ② TEMA·DEMA 둘 다 자홍 → B·C 패스 / TEMA·DEMA 청록 → C 후보
               (구 역배열 전환 '-' 대체, 2026-11-05)
5. 거래량    불리(숏 유리·매도+상회) → 패스 / C는 롱 유리 + 하회 아님 필수
     → 전략 확정 + 트리거 마감 확인. 미충족이면 그 전략은 여기서 끝(리포트에는 셋업 부합률·게이트·타이밍으로 표기, 2-11)
6. 보조지표   cRSI·스토캐스틱 반대 개수 → 0: ×1 / 둘 다 중립: ×0.75 / 1: ×0.5·지정가만 / 2: 대기
7. ① 비중    판정·맥락 TF 장기추세 → 2-2 매트릭스(둘 다 순행 ×1 / 둘 다 역행 ×0.5 / 그 외 ×0.75). 판정 TF 역행이면 트레일 금지·시간 손절 절반, A는 ×0.5 상한·T1 전량 (2026-11-06, 문구 정합화)
8. R:R       손절(구조) → P_max 계산 → 시가 ≤ P_max면 진입, 아니면 P_max 지정가 3봉
     → 수량 = floor(계좌 × 최종 리스크% ÷ (손절폭 × 포인트 가치)). 0이면 마이크로로, 그래도 0이면 패스
```

> 리포트에서는 "패스"를 찬반으로 쓰지 않고 전략별 셋업 부합률·게이트·타이밍으로 표기합니다([2-11](#2-11-리포트-형식)). 최종 진입 판단은 CEO가 합니다.

> 1~5단계의 "패스"는 정식(100%) 판정이다. 100% 미만 진입은 셋업 부합률 구간(40% 이상)으로 따로 판정하며, 여기서 패스인 조건은 부합률 항목 0점과 ⚠ 경고로 반영된다([2-5](#구간별-진입-검증-변형-tier)). (2026-11-06, TIER v2 · CEO 결정 · 수학자 설계)

### 2-1. 용어

| 용어 | 뜻 |
| --- | --- |
| **판정 TF / 맥락 TF** | 판정 TF = 조건을 읽는 봉(스윙 기본 일봉). 맥락 TF = 한 단계 위 봉(스윙 기본 주봉). ① 배수와 목표 상한(R_ctx)에 씁니다([2-4](#2-4-운용-모드-데이--스윙)) (2026-11-06, 트레이더 리뷰) |
| **마감봉** | 판정 TF 봉이 끝난(확정된) 봉. 모든 조건은 마감봉 기준 |
| **트리거 / 체결** | 트리거 = 전략 필수 조건이 **처음으로 모두 성립한 마감봉**. 체결은 [2-6](#2-6-진입--청산-플레이북)의 진입 방식(시가 또는 P_max 지정가)을 따름 |
| **N봉 창** | "최근 3·5·10봉 내"는 **트리거 봉을 포함**해 셉니다 |
| **R** | 1회 거래의 계획 손실 = 진입가와 손절가의 거리. "2R 목표" = 손절폭의 2배 이익 |
| **축** | 절대 기준 5축 = 지지/저항(⑤ + VRVP 보강) · 변동성(④ + %R 원) · 교차(③) · 기울기(②) · 거래량(VPT). 진입 자격과 트리거를 정함 |
| **상태 (유리 / 중립 / 불리)** | 각 축이 포지션 방향에 유리한지, 어느 쪽도 아닌지, 불리한지. 판정표는 [2-2](#2-2-판정-위계와-상태-점수판) |
| **최소 상태** | 전략별로 각 축이 넘어야 하는 문턱(필수 게이트). 못 미치면 패스 |
| **필수 / 가점** | 필수는 하나라도 빠지면 진입하지 않음. 가점 = 최소 상태를 넘는 축의 "유리" + 전략표 가점 행. 가점 개수로 기본 리스크를 정함 |
| **보조 배수** | cRSI·스토캐스틱의 확인/중립/반대 개수로 정하는 비중 배수(×1.0 / ×0.75 / ×0.5 / 대기) |
| **① 배수** | 판정 TF·맥락 TF ① `장기추세`의 순행/역행으로 정하는 비중 배수(×1.0 / ×0.75 / ×0.5). 사이징에만 쓰며 값은 [2-2](#2-2-판정-위계와-상태-점수판) 매트릭스를 따른다. 트레일·시간 손절·목표는 `판정 TF ① 역행`이 정한다 (2026-11-06, 문구 정합화) |
| **판정 TF ① 역행 (청산 제한)** | 판정 TF ① `장기추세`가 포지션 반대 계열인 상태(반대 계열 `약한 …` 포함, `-` 제외). 맥락 TF와 무관하게 판정한다. 걸리면 잔량 트레일 금지(T2에서 전량) · 시간 손절 절반(올림) · A는 ① 배수 상한 ×0.5와 T2 없이 T1 전량. 2절에서 수식어 없이 쓴 "① 역행"은 이것을 뜻한다. ① 배수(사이징)는 이것과 별개로 매트릭스를 따른다 (2026-11-06, 문구 정합화) |
| **순행 / 역행** | ① 셀이 포지션과 같은 방향 계열이면 순행, 반대 계열이면 역행. 롱 순행 = 상승 계열, 숏 순행 = 하락 계열 |
| **상승 계열 / 하락 계열** | ① 셀 값 기준. 상승 계열 = `골든 크로스`, `상승 (…)`, `강한 상승 (…)`, `약한 상승 (…)`. 하락 계열 = `데드 크로스`, `하락 (…)`, `강한 하락 (…)`, `약한 하락 (…)` |
| **ATR** | ATR = ATR(14), 판정 TF, Wilder RMA: TR = max(H−L, \|H−C₋₁\|, \|L−C₋₁\|), 첫 값 = 첫 14개 TR 평균, 이후 ATR_t = (13·ATR_{t−1} + TR_t)/14. 최소 100봉으로 계산. TradingView 내장 ATR(14)을 읽을 수 있으면 그 값 우선(메인 4종 테이블에는 없음). SMA 근사 또는 100봉 미만이면 `ATR 근사(SMA·n봉)`로 표기하고 경계 판정은 보수 쪽으로: P_cap·근접·임박에는 RMA와 SMA 중 작은 값, 손절 버퍼 0.25 ATR에는 큰 값. 반올림 때문에 경계에 걸린 값은 금지·미충족 쪽으로 본다. ATR% = ATR ÷ 종가 × 100 (2026-11-06, 트레이더 리뷰) |
| **임박** | 테이블 전환 %의 절댓값이 **0.5 × ATR% 이하**(예: ATR% 1.8%면 ±0.9% 이내). 운영 정의, 미검증 |
| **P_max** (숏: P_min) | 손절폭 상한과 최소 R:R을 동시에 지키는 **최고 진입가**(숏은 최저 진입가). 공식은 [2-6](#2-6-진입--청산-플레이북) |
| **기준 저점 L · L2** (숏: H · H2) | L = B에서 최근 10봉 최저 저가. L2 = C에서 최근 3~10봉 눌림 구간(③ `Sonar 교차` 자홍 또는 ② `TEMA 전환` 자홍이었던 봉들)의 최저 저가. H·H2는 대칭(최고 고가, 청록 구간) |
| **지지 / 저항 형성** | 기준 저점(고점) 이후 마감봉 2개 이상이 그 값을 갱신하지 않은 상태(B1·C1). B는 그 기간 동안 교차·워킹 해제가 2봉 연속 유지되어야 함(B4) |

**점수판 → 행동 · 비중**

**최종 리스크% = 기본 리스크(전략·가점) × 보조 배수 × ① 배수 × 구간 배수([2-5 TIER](#구간별-진입-검증-변형-tier): 정식 ×1.0 · TIER-80 ×0.75 · TIER-60 ×0.5 · TIER-40 ×0.4).** 결과가 **0.2% 미만이면 패스**합니다. (2026-11-06, TIER v2 · CEO 결정 · 수학자 설계)

| 단계 | 상태 | 행동 / 배수 |
| --- | --- | --- |
| 1. 절대 기준 | 전략 최소 상태 미충족 | **패스** (리포트에는 셋업 부합률·게이트·타이밍으로 표기, [2-11](#2-11-리포트-형식)) |

- `약한 …`의 방향: 포지션과 같은 계열의 `약한`(롱의 `약한 상승`, 숏의 `약한 하락`)만 ×0.75 행으로 본다. 반대 계열의 `약한`(숏의 `약한 상승`)은 역행으로 센다. (2026-11-06, 트레이더 리뷰)

| 판정 TF \ 맥락 TF | 순행 | 약한 순행 · `-` | 역행 · 약한 역행 |
| --- | --- | --- | --- |
| 순행 | ×1.0 | ×0.75 | ×0.75 |
| 약한 순행 · `-` | ×0.75 | ×0.75 | ×0.75 |
| 역행 · 약한 역행 | ×0.75 | ×0.75 | ×0.5 |

- 매트릭스는 사이징 전용이다. 트레일·시간 손절·A 목표는 4-1 청산 제한(판정 TF ① 역행)으로만 바뀐다. 예: 판정 TF 역행 + 맥락 TF 순행이면 B·C는 ×0.75 + 청산 제한, A는 ×0.5 + 청산 제한. 판정 TF 순행 + 맥락 TF 역행이면 ×0.75에 청산은 정상이다(맥락 TF 저항은 [2-4](#2-4-운용-모드-데이--스윙) R_ctx 목표 상한이 맡음) (2026-11-06, 문구 정합화)

- 검토 후 기각(2026-11-06, 수학자): 숏의 반대 계열 `약한 상승`을 ×0.75로 보는 안 — `약한`은 전환이 아닌 간격 축소이고 전환 확률 자료가 없으며, 드리프트 역풍이 있는 숏만 비중을 올리는 비대칭이다.

- 0.2% 하한 조견표: ① ×0.5일 때 규칙상 진입이 가능한 조합은 역추세(가점 ≥ 2 · 보조 ×1.0), 추세 예측(가점 ≥ 3 · 보조 ×1.0), 추세 확정(가점 ≥ 2 · 보조 ≥ ×0.5, 또는 가점 0~1 · 보조 ×1.0)뿐이다. 판독 첫 단계에서 이 조합에 해당하지 않으면 리스크 칸에 `구조적 0.2% 미만`을 먼저 적는다. (2026-11-06, 트레이더 리뷰) A는 판정 TF ① 역행이면 매트릭스 값과 무관하게 이 ×0.5 조합을 적용한다 (2026-11-06, 문구 정합화).

- 가점을 셀 때 같은 사실은 한 번만 셉니다(예: A에서 거래량 A형 유리 = 가점 a3, ⑤ `100선`/`200선` 녹 = 가점 a1).

### 2-5. 공통 리스크 · 사이징

- 기댓값(R 단위): **E = p·R − (1 − p)**, 손익분기 **R\* = (1 − p) / p**. 일봉 갭을 반영해 평균 손실을 L = 1.1R로 가정 → **E = p·R − 1.1·(1 − p)**. 분할 청산의 R은 가중 평균.

| 가정 승률 p | 30% | 35% | 40% | 45% | 50% | 55% |
| --- | --- | --- | --- | --- | --- | --- |
| 손익분기 R\* (L=1.0) | 2.33 | 1.86 | 1.50 | 1.22 | 1.00 | 0.82 |
| 손익분기 R\* (L=1.1) | 2.57 | 2.04 | 1.65 | 1.34 | 1.10 | 0.90 |

- **손절폭 상한**: 세 전략 모두 손절폭 > **1.5 × ATR**(판정 TF)이면 진입하지 않습니다(검증 변형 예외: B 롱 BV2는 2.0 ATR, [2-8](#2-8-전략-b--추세-예측)). 손절 버퍼는 구조 기준점 ∓ **0.25 ATR**입니다.
- **최소 R:R**: A 가중 1.5 · T1 ≥ 1.0R / B 가중 2.5 · T1 ≥ 1.5R / C 가중 2.0 · T1 ≥ 1.5R.

**사이징**

```
최종 리스크% = 기본(전략·가점) × 보조 배수 × ① 배수 × 구간 배수(TIER, 정식 ×1.0)   (< 0.2% → 패스)
수량 = floor( 계좌 × 최종 리스크% ÷ (손절폭 × 단위당 가치) )
```

단위당 가치: NQ = $20/pt, MNQ = $2/pt, CME BTC = 5 BTC, CME MBT = 0.1 BTC, 현물 = 1 BTC 단위. 주식 = 1주(KRX 원, 미국 달러). 0주면 패스(소수점 주식은 검증 변형) (2026-11-06, 트레이더 리뷰).

**계좌 미지정**: 수량 대신 ① 1단위당 리스크 = 손절폭 × 단위당 가치, ② 1R 금액 = 표준 계좌 × 최종 리스크%(표준 계좌: KRX 1억 원, 미국 주식·NQ·BTC $100,000), ③ 최소 계좌 = 1단위당 리스크 ÷ 최종 리스크%를 적고 `표준 계좌 가정`을 표기한다. (2026-11-06, 트레이더 리뷰)

| 예시 (가상) | 계산 | 결과 |
| --- | --- | --- |
| NQ 스윙 C, 계좌 $200,000, 1.0% × 1.0 × ① 0.75 = 0.75% = $1,500, 손절 260pt | MNQ $520/계약 → 2.88 / NQ $5,200 | **MNQ 2계약**(실 리스크 $1,040 = 0.52%) / NQ 0 → 불가 |
| NQ 데이 B, 0.5% × 0.5 × 1.0 = 0.25% = $500, 1H 손절 45pt | MNQ $90 → 5.55 | MNQ 5계약($450) |
| BTC 스윙 A, 0.5% × 1.0 × 0.5 = 0.25% = $500, 손절 $2,400/BTC | 현물 0.208 BTC / CME MBT(0.1 BTC) $240 → 2.08 / CME BTC(5 BTC) $12,000 | 현물 0.208 BTC 또는 **MBT 2계약** / BTC 0 |

**0계약 원칙**
1. 손절을 좁혀서 수량을 맞추지 않는다.
2. 같은 리스크로 상품을 내린다(NQ → MNQ, BTC → MBT/현물).
3. 그래도 0이면 패스한다. 올림 금지.
4. 분할은 3 이상 되는 마이크로 수량을 우선한다.
5. 실현 리스크%를 로그에 남긴다.

실행 가능성은 셋업 부합률 항목이 아니다. 리포트 별도 칸(`실행: 가능 / 제한 / 불가 / 미확인`)에 적는다. 구체 제도 수치는 시점·증권사마다 다르므로 진입 전 확인.

#### 구간별 진입 (검증 변형 TIER)

> 이 소절은 **검증 변형**이며 정식 규칙이 아니다. 정식 진입은 셋업 부합률 100%([2-11](#2-11-리포트-형식))뿐이고, 100% 미만은 아래 구간 규칙에 따라 줄인 비중으로 들어가 엣지를 검증한다. 구간 경계(40·60·80%)와 구간별 판단 방식은 CEO 결정이다. 이 소절의 모든 문구 출처: (2026-11-06, TIER v2 · CEO 결정 · 수학자 설계)

**A. 원칙**

- 구간은 리포트의 **셋업 부합률(진행도) 그 자체**에 적용한다. 별도 환산 %는 없다(구 `체결 기준 구간` 폐지).
- 세 전략(역추세 · 추세 예측 · 추세 확정) 모두에 적용하고, 롱·숏 대칭이다(숏은 [2-1-1](#2-1-1-숏-변환표-롱--숏)대로 바꿔 읽는다).
- 셋업 부합률은 진행도이며 승률이 아니다(미보정). 구간 이름의 "기술적 신뢰"는 승률을 뜻하지 않는다.
- 전제 게이팅([2-11](#2-11-리포트-형식)) 0%는 그대로다. 0%는 40% 미만이므로 진입 없음.
- **게이트(전략표 금지 행, [2-2](#2-2-판정-위계와-상태-점수판) 거래량 불리 등)는 부합률 항목 하나(0점)로만 반영한다.** 구간 판정은 %로 하고, 해당 금지 사실은 리포트 같은 행에 `⚠ 금지: …`로 남긴다. 단 아래 F의 절대 금지 X1~X4는 %와 무관하게 주문하지 않는다.
- 판독 항목 중 **미확인이 하나라도 있으면** 구간은 `— (구간 미확인)`이다(미확인을 분모에서 빼면 %가 부풀기 때문). 판독을 보완한 뒤 다시 판정한다.
- 같은 종목·같은 방향에서 둘 이상 전략이 구간에 들면 셋업 부합률이 가장 높은 전략 1개만 쓴다(동률이면 기본 리스크가 낮은 전략). 같은 방향 중복 진입 금지([2-5](#2-5-공통-리스크--사이징) 포트폴리오 한도)는 그대로다.

**B. 구간표**

| 셋업 부합률 | 태그 | 성격 (CEO) | 구간 배수 | 진입 방식 | 구간 트리거 | 시황 M1~M5 | 시간 손절 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 100% | 정식 | 정식 규칙 | ×1.0 | 현행 (a)/(b) | — (정식 트리거) | 기록만 | 현행 |
| 80~<100% | TIER-80 | 시황과 무관하게 기술적 신뢰로 매매 | ×0.75 | P_max(숏 P_min) 지정가, 3봉 | 불요 | 기록만(거부권 없음) | 현행 |
| 60~<80% | TIER-60 | 기술적 신뢰를 바탕으로 시황을 판단해 진입 | ×0.5 | P_max(숏 P_min) 지정가, 3봉 | 필요 | 역풍 0개 · 미확인 ≤ 1 | 절반(올림) |
| 40~<60% | TIER-40 | 기술적 최소 후보. 시황이 허락할 때 진입 | ×0.4 | P_max(숏 P_min) 지정가, 3봉 | 필요 | 역풍 0개 · 미확인 ≤ 1 · 지수(M1) 또는 섹터(M3) 순풍 ≥ 1 | 절반(올림) |
| < 40% (0% 포함) | — | 금지 | — | 주문 없음 | — | — | — |

- 경계는 하한 포함이다(40.0% = TIER-40, 60.0% = TIER-60, 80.0% = TIER-80).
- **진입 방식**: 100% 미만은 모두 P_max(숏 P_min) 지정가다. 매수 지정가이므로 시가 ≤ P_max면 시가에 체결된다. (a) 시장가, 마감 직전 선진입, (c) 분할은 쓰지 않는다. 지정가는 주문 봉 다음 봉부터 판정 TF 3봉 유효하다. 가격 항목이 0점(멂)이어도 주문은 P_max에 두되, 기준가에서 P_max까지 1.5 ATR을 넘으면 [2-6](#2-6-진입--청산-플레이북)대로 주문하지 않고 `멂 x.x ATR — 체결 비현실`로 적는다.
- P_max 지정가가 최소 R:R을 보장한다(P_max 정의상 손절폭 ≤ 1.5 ATR · T1 · 가중 최소 R:R이 성립). 그래서 가격 항목 점수와 별개로 R:R은 항상 지켜진다.
- ① 배수는 구간과 무관하게 [2-2](#2-2-판정-위계와-상태-점수판) 매트릭스대로 곱한다. TIER-80 숏은 ① 판정·맥락 TF `장기추세`가 둘 다 상승 계열(① ×0.5)이어도 허용하며 ① 배수로만 반영한다(구 G13 폐지).
- 보조 배수와 그 진입 방식 규칙([2-2](#2-2-판정-위계와-상태-점수판) 3단계: 반대 1개 지정가만 · 반대 2개 대기)은 그대로 적용한다.
- 시간 손절 "절반(올림)"은 역추세 4봉 · 추세 예측 5봉 · 추세 확정 8봉이다. 판정 TF ① 역행으로 이미 절반이면 한 번만 적용한다.
- 트레일·분할 익절·소프트 손절은 현행과 같다(판정 TF ① 역행 청산 제한 포함).
- **최종 리스크% = 기본 × 보조 × ① × 구간 배수 (× 이벤트 등)**. 모두 곱한 뒤 0.2% 미만이면 주문하지 않고 `하한 미달(TIER)`로 로그를 남긴다.
- 0.2% 하한 조견(이벤트 배수 없음 기준): 역추세·추세 예측은 TIER-80에서 기본 0.5%이고 보조·① 모두 ×0.75 이상일 때, TIER-60·TIER-40에서는 기본 0.5% · 보조 ×1.0 · ① ×1.0일 때만 성립한다. 추세 확정은 TIER-60·TIER-40에서 기본 1.0%이면 보조 × ① ≥ 0.5일 때, 기본 0.5%이면 보조 ×1.0 · ① ×1.0일 때 성립한다. 매크로 이벤트 창(×0.5)이 겹치면 역추세·추세 예측의 TIER-60·TIER-40은 모두 하한 미달이다. 이것이 설계상 정상이다.

**C. 구간 결정 시점과 구간 트리거**

- 구간은 **주문을 내는 마감봉의 셋업 부합률**로 정한다. TIER-80은 판독 마감봉, TIER-60·TIER-40은 구간 트리거 봉이다(그 봉으로 다시 채점).
- **구간 트리거** = 셋업 부합률이 40% 이상이 된 첫 마감봉부터 3봉 안(그 봉 포함)의 첫 진입 방향 마감(롱: 종가 > 직전 종가 / 숏: 종가 < 직전 종가). 셋업 부합률의 트리거 항목이 1인 봉도 구간 트리거로 인정한다.
- 3봉 안에 없으면 소멸한다. 40% 미만으로 내려갔다가 다시 40% 이상이 되면 그 봉부터 새로 센다. 구간 트리거 봉의 셋업 부합률이 40% 미만이면 무효다.
- 장중 성립은 근거가 아니다(마감봉만). 셋업 부합률의 트리거 항목 정의는 그대로이고, 구간 트리거는 점수에 넣지 않는다. 숏 표기는 [2-1-1](#2-1-1-숏-변환표-롱--숏) `구간 트리거` 행.

- 판단: M1~M4는 트레이더가 규칙으로 판독하고, M5와 최종 서명은 애널리스트(부재 시 본부)가 한다. 판정은 위 규칙으로만 하며 재량 거부권 · 재량 승인은 없다.
- 시황으로 막힌 건은 `MKT-BLOCK` 가상 체결로 기록한다.

**F. 절대 금지** (셋업 부합률과 무관하게 주문 없음. TIER-80 이상과 정식 100%에도 같음)

| # | 금지 | 표기 | 근거 |
| --- | --- | --- | --- |
| X1 | 개별주 실적 이벤트 창 안 신규 진입([2-4](#2-4-운용-모드-데이--스윙)) | 게이트 `⚠ 금지: 실적 D-1`(0점) + `절대 금지 X1` | 실적 갭은 손절로 막히지 않는다. 평균 손실 L = 1.1R 가정이 깨진다 |
| X2 | 현물 개별주 숏에서 `실행: 가능`이 아님. 주문 직전 다시 확인하고 `제한`·`미확인`·`불가`로 바뀌면 주문 취소(선물·BTC는 해당 없음) | `실행: …` 칸 | 차입·규제상 주문이 실행되지 않는다 |
| X3 | 손절 무효: 기준가·시가가 이미 손절가 이하(숏 이상)이거나 `⚠ 프리뷰 무효`(장중 손절가·기준점 이탈) | `마감 후 재산출` | R을 정의할 수 없다 |
| X4 | R6 노출 한도 초과 또는 R7 서킷브레이커 발동 중 | `한도 초과` / `TIER 중단` | 계좌 단위 손실 한도 |

- 위 네 가지 말고 전략표 금지 행(④ 확장 워킹, ⑤ 반대색, %R 원, 거래량 불리, 되돌림 주의·확실 등)은 **모두 게이트 0점 + ⚠ 경고**로만 반영한다.

**G. 지정가 대기 중 (히스테리시스)**

- 매 마감마다 셋업 부합률 전 항목을 다시 채점한다.
- 같은 구간 이상이면 주문을 유지한다. 올라가도 증액하지 않는다. 100%가 되면 TIER 주문을 취소하고 정식 규칙으로 P_max · 수량을 다시 계산해 주문한다(중복 진입 아님).
- 아래 구간으로 내려가면 주문을 취소하고, 그 마감봉을 새 구간의 판독으로 본다(TIER-60 · TIER-40이면 구간 트리거 · 시황 조건을 다시 충족해야 함). 40% 미만이면 취소만 한다.
- 전략표의 진입 전 취소 조건, X1~X4, M4 이벤트 창(TIER-60 · TIER-40)이 나오면 취소한다. 새 구조(새 L · L2)가 생기면 P_max를 다시 계산한다([2-6](#2-6-진입--청산-플레이북)).
- 체결 후에는 구간을 고정한다(체결 시 가격 항목이 1점이 되어 %가 올라도 바꾸지 않는다).

**H. 판독 로그** (필수 12필드, 나머지는 스크립트 파생)

1. 판독 ID(종목·TF·마감일·전략·방향)
2. 항목별 점수 문자열(원점수 포함)
3. 게이트(⚠ 금지 사실 원문)
4. 구간 태그 · 주문 봉 셋업 부합률
5. 구간 트리거 봉 시각(TIER-60 · TIER-40)
6. M 문자열 · 판단자 · 작성 시각(TIER-60 · TIER-40 후보, TIER-80은 기록만)
7. P_max(P_min) · S · T1 · T2 · ATR(R4 목표 상한을 썼으면 R_v)
8. 배수 문자열 → 최종 리스크%
9. 상태(체결 / 놓침 / 페이퍼 / MKT-BLOCK / 하한 미달 / 취소·사유)
10. 체결가
11. 청산가 · 사유 · 보유 봉 수
12. R(비용 전)

- 숏은 실행 상태(차입 수량·수수료·SSR/과열·리콜) · 손절 슬리피지 · 갭 손실을 추가한다. MAE · MFE · 비용 후 R은 수학자가 사후 계산한다.
- `MKT-BLOCK` · `하한 미달` · `놓침`은 주문했다면의 가상 R을 수학자가 사후 계산한다(실체결과 섞지 않음).

**I. 검증 판정**

- 태그: `TIER-80` / `TIER-60` / `TIER-40` / `MKT-BLOCK`(가상) / `하한 미달`(가상).
- 구간별로 n ≥ 30에서 비용 포함 E[R] ≤ 0이면 그 구간 폐기, n ≥ 15이고 E[R] ≤ −0.3R이면 조기 중단한다. 방향 셀(롱 · 숏 각각)도 n ≥ 15이고 E[R] ≤ −0.3R이면 그 방향 TIER를 조기 중단한다.
- **게이트 0점 체결분**(⚠ 금지 사실이 있던 체결)은 따로 집계한다. n ≥ 15이고 E[R] ≤ −0.3R이면 본부장을 거쳐 CEO에 보고한다(자동 중단 아님).
- 배수 상향은 n ≥ 60, 90% 단측 하한 > 0, 구간 간 단조성(TIER-80 ≥ TIER-60 ≥ TIER-40)이 성립할 때만 한다. 경계(40/60/80)와 배수는 판정 전까지 바꾸지 않는다.
- 검정은 구간 단위(3개, Holm 보정)로 하고, 전략 · 방향 · 게이트 셀은 기술통계만 낸다. 가상 체결은 시황 필터와 하한의 효과를 재는 데만 쓴다.

**예시**

- 네이버 추세 확정 롱(11-06): 셋업 부합률 69%(C1 0.5 · C2 1 · C3 1 · C4 1 · C5 1 · 게이트 1 · 가격 0 · 트리거 0) → `TIER-60 후보 — 구간 트리거 · 시황 대기`. 구간 트리거(상승 마감)와 시황 역풍 0개가 나오면 P_max 지정가 3봉, 구간 배수 ×0.5, 시간 손절 8봉.
- 삼성전자 역추세 롱(11-06): 셋업 부합률 57%(4/7, 게이트 0 · 트리거 0 · A3 0, `⚠ 금지: ④ 하락확장(50) 워킹 7봉째`) → TIER-40 후보. 그러나 0.5% × 보조 0.75 × ① 0.75 × 구간 0.4 = 0.11%로 `하한 미달(TIER)`이고, 11-10 CPI 이벤트 창이 걸리는 봉은 0.06%다. 주문하지 않고 가상 체결로만 기록한다.

### 2-6. 진입 · 청산 플레이북

**진입 방식 3가지**

| 방식 | 조건 | 규칙 |
| --- | --- | --- |
| (a) 트리거 마감 후 시가 | 시가 ≤ P_max, 보조 반대 0개 | 다음 세션(봉) 시가에 시장가 |
| (b) 눌림 지정가 (기본 대응) | 트리거 종가 > P_max, 또는 보조 반대 1개 | P_max에 지정가, 판정 TF 기준 3봉 유효. 매 마감마다 절대 기준이 깨지거나 진입 전 취소 조건이 나오면 주문 취소. 미체결이면 "놓침"으로 기록 |
| (c) 분할 | **검증 변형**(기본 아님) | 1/2 시가 + 1/2 지정가 L = 2·P_max − 시가 |
| 마감 직전 선진입 | 예외 옵션(기존 유지) | 계획 수량의 절반. 마감 뒤 조건이 깨지면 다음 시가에 청산 |

- **(b) 체결 현실성**: 트리거 종가에서 P_max까지 거리가 1.5 ATR을 넘으면 3봉 지정가를 두지 않고 `멂 x.x ATR — 체결 비현실`로 기록한다. 새 구조(B: 새 L, C: 새 L2)가 생기면 P_max를 다시 계산한다. 1.0~1.5 ATR 구간은 지정가를 둘 수 있으나, 체결되면 그 봉 종가로 진입 전 취소 조건을 다시 확인하고 L·L2 저가 이탈이 났다면 체결분은 소프트 손절 대상이다. 거리는 ATR 배수와 %를 함께 적는다. (1.5 ATR은 손절 상한과 맞춘 운영 가정, 미검증) (2026-11-06, 트레이더 리뷰)

**손절·청산**
- **하드 손절**: 구조 기준점 ∓ 0.25 ATR. 체결 직후 거래소 스톱을 겁니다.
- **소프트 손절**: 마감봉으로 판정하고 다음 시가에 실행합니다.
- **분할 익절**: A는 50/50, B·C는 1/3씩.
  - 수량이 3 미만이면: 1개일 때 A·B는 T1에서 전량, C는 T1에서 본전 이동 후 트레일만(판정 TF ① 역행이면 C도 T1에서 전량) (2026-11-06, 문구 정합화). 2개일 때 T1 1개, 잔량 1개.
  - R:R 검사는 실제 분할 비율로 다시 계산합니다.
- **트레일**: 각 전략표의 잔량 규칙을 따릅니다. 판정 TF ① 역행이면 트레일 금지(잔량은 T2에서 전량). 맥락 TF만 역행이면 트레일 정상 (2026-11-06, 문구 정합화).
- **시간 손절**: A 7봉 / B 10봉 / C 15봉. 판정 TF ① 역행이면 절반(올림: 4·5·8봉) (2026-11-06, 문구 정합화).
- **보유 중 ① 반대 전환**(판정 TF 또는 맥락 TF ① `장기추세`가 보유 중 역행 계열로 바뀐 마감봉, 맥락 TF는 그 TF 마감 기준): 청산하지 않습니다. 잔량 트레일을 중단하고 손절을 본전으로 당깁니다. T1 미도달이면 진입가 − 0.5R로 당깁니다. (2026-11-06, 문구 정합화)

**P_max 공식** (롱 기준, 숏은 [2-1-1 표](#2-1-1-숏-변환표-롱--숏)대로 P_min (2026-11-06, 트레이더 리뷰))

```
S = 구조 손절가, C = 1.5 (ATR 배수), k1 = T1 최소 배수, W = 가중 최소 R:R, 목표 T_i 가중 w_i
P_cap = S + C·ATR
P_T1  = (T1 + k1·S) / (1 + k1)
P_W   = (Σ w_i·T_i + W·S) / (1 + W)        (트레일 잔량은 T1로 보수 계산)
P_max = min(P_cap, P_T1, P_W)
```

- T_i는 맥락 TF 상한([2-4](#2-4-운용-모드-데이--스윙)) 적용 후 값 (2026-11-06, 트레이더 리뷰).
- **목표 후보 부재**: 전략표의 T1 후보가 진입 방향 쪽에 하나도 없으면 P_T1을 산출하지 않는다. 가격 항목은 `산출 전 — 목표 후보 없음` 0점이며 규칙상 진입은 성립하지 않는다. 후보 레벨을 전략표 밖에서 새로 만들지 않는다. (2026-11-06, 트레이더 리뷰)
- 검토 후 기각(2026-11-06, 수학자): 목표 후보가 없을 때 20봉 극값·VRVP VAL/POC를 대체 T1으로 쓰는 안 — 후보 부재는 주로 B에서 가격이 이미 ⑤ `50선`을 진입 방향 쪽으로 넘어선 추격 상황이며(중립 위치 전제 붕괴), C의 T1은 이미 직전 스윙 극값이다.
- ⑤ 선이 진입 방향 반대편(숏: 가격 위)에 있으면 목표가 아니라 손절·불리 판정 재료다. (2026-11-06, 트레이더 리뷰)

가상 예시: NQ, S = 20,000, ATR = 300, T1 = 20,900, k1 = 1.5
- P_cap = 20,450, P_T1 = 20,360 → P_max = 20,360 (이 예시는 T1만 주어져 P_W를 생략. 실제로는 P_W도 계산해 셋 중 최솟값을 씀)
- 트리거 종가가 20,520이면 T1 = 0.73R로 미달이다.
- 20,360 지정가로 체결되면 R = 360, T1 = 1.5R이다. 필요한 되돌림은 0.53 ATR이고, 3봉 안에 닿을 확률은 약 60~70%(랜덤워크 근사)다.
- 주의: 역선택이 있다(바로 가는 승자는 놓친다). 체결률과 미체결분의 가상 E[R]을 측정해야 한다(미검증).

**충돌 완화 변형** (검증용, 기본 아님): (2) 분할, (3) 손절 기준점 재정의(트리거 직전 2봉 극값 / ⑤ 녹 선 아래), (4) B·C의 T1 ≥ 1.5R을 1.0R로 완화(가중 기준은 유지). (5) 1.5 ATR 상한은 유지한다. 예외: B 롱 검증 변형 BV2([2-8](#2-8-전략-b--추세-예측))는 (3)의 트리거 직전 2봉 극값(L 이후 higher low)을 손절 기준점으로 쓰고 상한을 2.0 ATR로 둔다.

### 2-7. 전략 A — 역추세

> **A 역추세 — 극단 위치에서 평균 쪽으로.** 가격이 과매도(과매수) 구간에 있을 때 반대 방향, 즉 평균 쪽 되돌림을 짧게 노린다. 비추세 국면이 기본 무대이며, 추세 국면에서는 추세 반대 방향으로만 쓰고 비중을 줄인다(추세 방향 진입은 C의 몫). 극단이 추세의 시작일 수 있어(칼날 잡기) 반전 마감을 확인한 뒤 들어간다. 승률은 높고 R은 작다고 **가정**한다(미검증).

> 20봉 위치 극단(이격도 + %R 원)에서 평균 쪽 되돌림을 짧게 먹는다. ①은 자격 조건이 아니라 비중 조정이다. 승률은 높고 R은 작다고 **가정**한다.

### 2-11. 리포트 형식

> **CEO 원칙(2026-11-05)** — 트레이더·본부 리포트는 **진입 찬성/반대(권고/반대, 진입 불가 판정)를 내지 않습니다. 최종 진입 판단은 CEO가 합니다.** 리포트는 전략별 **부합률(%)**과 **진입한다면의 시나리오**를 사실대로 보고합니다. 매매 규칙(필수·금지·사이징)은 그대로이며, 2절의 "패스"·"금지"는 규칙의 판정이고 리포트에서는 아래 형식으로 표기합니다.

> 리포트에서는 전략을 A·B·C 기호가 아니라 이름(역추세·추세 예측·추세 확정)으로 쓰고, 조건 번호는 뜻을 함께 적는다(CEO, 2026-11-06).

**셋업 부합률** — 전략(A 역추세 · B 추세 예측 · C 추세 확정)별, 방향별로 따로 계산합니다. 셋업 부합률은 **규칙상 진입까지 얼마나 왔는지**를 잽니다. 셋업 구조 조건에 게이트(금지 미해당)·가격·트리거를 더해 세며, **100%는 정식 진입 성립과 같습니다**(2026-11-06 재개정, 알고리즘 수학자 설계, CEO). 100% 미만 진입은 검증 변형 TIER([2-5](#구간별-진입-검증-변형-tier))로만 성립한다. 구간 경계(80 · 60 · 40%)는 이 셋업 부합률에 그대로 적용하며, 아래 `구간` 열로 구분한다 (2026-11-06, TIER v2 · CEO 결정 · 수학자 설계).

```
셋업 부합률 = 항목 점수 합 ÷ 판정 가능한 항목 수 × 100     (마감봉 기준)
항목 점수: 충족 1 / 부분 0.5 / 미충족 0   (항목당 상한 1, 모든 항목 같은 가중치)
항목:
  A: A1 이격도 · A2 %R 원 · A3 지지/저항 · A4 거래량 · 게이트 · 가격 · 트리거                     (7개)
  B: B1 지지 형성 · B2 역행 경험 · B3 교차 B형 · B4 유지 · B5 기울기·거래량 · 게이트 · 가격 · 트리거 (8개)
  C: C1 L2 형성 · C2 교차 C형 · C3 기울기 · C4 거래량 C형 · C5 변동성 · 게이트 · 가격 · 트리거       (8개)
  게이트: 열림 1 / 금지 해당 0 / 금지 여부 미확인(해당 확정 없음)이면 분모에서 제외
  가격  : 도달 1 = S < 기준가 ≤ P_max (숏: P_min ≤ 기준가 < S) / 근접 0.5 = 기준가가 P_max 위 0.5 ATR 이내(숏 대칭)
          / 그 외 0   (A5·B6·C6 R:R 조건 포함)   (2026-11-06, 트레이더 리뷰)
          기준가 = 판정 TF 최근 마감 종가. 지정가 체결은 실제 사건이므로 체결 시 1점
  트리거: 이번 마감봉이 트리거 1 / 그 외 0
5축 최소 상태는 셋업 항목과 금지의 AND라 중복이므로 따로 세지 않음
```

**전제 게이팅** — 각 전략의 핵심 항목(방향을 가르는 항목) 중 1점(완전 충족)이 하나도 없으면 그 방향의 셋업 부합률은 **0%**로 적습니다. 핵심 항목은 역추세 A1 이격도·A2 %R 원, 추세 예측 B2 역행 경험·B3 교차 B형, 추세 확정 C2 교차 C형·C3 기울기입니다. 부분 점수(0.5)만으로는 전제가 충족되지 않습니다. 근거는 두 가지입니다. 첫째, 게이트(금지 없음)·"≥ 중립" 항목은 반대 방향에도 똑같이 점수를 주므로, 핵심 신호 없이 쌓인 점수는 진입 쪽으로 다가간 정도가 아닙니다. 둘째, 전환기의 (나)① 0.5는 롱·숏에 동시에 붙습니다. (2026-11-06, 알고리즘 수학자 설계, CEO)

- 표기: `0% (전제 없음 · 원 3/7)`. 원점수는 `충족 · 부분 · 미충족` 열과 로그에 그대로 남깁니다(보정용).
- 핵심 항목이 미확인이고 확인된 핵심 항목 중 1점이 없으면 `— (전제 미확인 · 원 x/y)`로 적고, 정렬은 0% 행과 같은 위치에 둡니다.
- 100%(정식 진입 성립)는 모든 핵심 항목이 1점이어야 하므로 게이팅과 무관하게 지금과 같습니다. 게이트·금지·가격·트리거·사이징 판정도 바뀌지 않습니다.
- 간단 리포트 정렬: 0% 행은 같은 게이트 그룹 안에서 맨 아래에 둡니다.
- 2026-11-20까지 병기하는 구 기준 %는 부록 산식 그대로 계산합니다(게이팅 미적용).

- **장중 프리뷰는 점수에 넣지 않습니다.** 형성 중 봉에서만 성립한 조건은 0점(금지는 마감봉 기준으로 판정)으로 세고, `충족 · 부분 · 미충족` 열과 게이트·타이밍 열에 `프리뷰`로 적습니다. 예: `⚠ 프리뷰 금지: ④ 위쪽 되돌림 주의`, 트리거 `장중 성립(프리뷰)`.
- **장중 리포트** = 직전 마감봉으로 채점한 점수 + 프리뷰 주석. 현재가(장중)는 `프리뷰`로만 적는다. 프리뷰는 양방향으로 적는다: `프리뷰 성립: …`(점수 0) / `프리뷰 붕괴: …`(점수는 마감봉 값 유지, 다음 마감에 0이 될 수 있음 표기). 게이트의 프리뷰 금지는 점수에 반영하지 않고(직전 마감봉 게이트 사용) `⚠ 프리뷰 금지`로 표기만 한다. N봉 창·미갱신 봉 수는 마감봉만 센다(형성 중 봉 제외). (2026-11-06, 트레이더 리뷰)
- **장중 무효 프리뷰**: 판독 시점 장중 저가가 하드 손절가 이하이거나 기준 저점 L·L2(숏: 고가 ≥ 손절가 또는 H·H2 초과)를 넘어서면 그 전략 행 게이트 열에 `⚠ 프리뷰 무효: 장중 손절가/L 이탈`을 적고 진입가·손절·목표는 "마감 후 재산출"로 둔다. 걸어 둔 지정가가 있으면 진입 전 취소 사안으로 즉시 보고한다. (2026-11-06, 트레이더 리뷰)
- 부분 점수는 **% 계산 전용**입니다. 필수 충족, 트리거, 게이트, 가점, 사이징 판정에서는 0.5를 **미충족**으로 봅니다.
- B 롱 BV2([2-8](#2-8-전략-b--추세-예측))의 V2를 쓰면 B4는 1봉 성립으로 1점이고, 태그 `V2`를 함께 적습니다. 다른 V 조항으로만 성립한 항목도 사용한 조항을 적습니다. C 롱 CV1로 금지가 풀린 게이트는 열림(1점)으로 채점하고 태그 `CV1`을 적습니다.
- 미확인 항목(셀 값·ATR 확인 불가 등)은 **분모에서 빼고** 따로 적습니다. 예: `B 43% (3/7, 미확인 1: 게이트)`.
- 금지에 해당하면 게이트가 0이므로 부합률은 A 최대 86%, B·C 최대 88%입니다. 정식(100%)은 성립하지 않지만, 100% 미만 구간 진입은 이 %로 판정하고 금지 사실은 게이트 열에 `⚠`로 남깁니다. 절대 금지([2-5](#구간별-진입-검증-변형-tier) X1~X4)는 %와 무관하게 주문하지 않습니다 (2026-11-06, TIER v2 · CEO 결정 · 수학자 설계).
- 핵심 항목 1점이 없으면 0%(전제 게이팅).
- 항목별 점수를 함께 적습니다. 예: `C1 0.5 · C2 1 · C3 1 · C4 1 · C5 1 · 게이트 1 · 가격 0 · 트리거 0`.

**게이트 열** — `열림`, `⚠ 금지: <해당 금지 조건>`, 또는 `⚠ 프리뷰 금지: <조건>`. 금지에 해당하면 정식(100%) 진입은 성립하지 않으며, 100% 미만 구간 진입은 게이트 0점이 반영된 셋업 부합률로 판정합니다. 어느 경우든 금지 사실을 반드시 같은 행에 적습니다. 절대 금지에 해당하면 `⚠ 금지: 실적 D-1 · 절대 금지 X1`처럼 X 번호를 붙입니다([2-5](#구간별-진입-검증-변형-tier)) (2026-11-06, TIER v2 · CEO 결정 · 수학자 설계).

**타이밍 열** — 두 가지를 함께 적습니다(점수는 위 항목 정의를 따름).
- 트리거: `마감`(이번 마감봉이 트리거) / `장중 성립(프리뷰)`(형성 중 봉 기준으로 필수 조건이 모두 성립, 마감 전, 0점) / `대기 — <남은 조건>`
- 가격(P_max, 숏은 P_min 기준, 기준가 = 판정 TF 최근 마감 종가): `도달`(롱: S < 기준가 ≤ P_max, 숏: P_min ≤ 기준가 < S) / `근접`(0.5 ATR 이내. [2-6](#2-6-진입--청산-플레이북) P_max 지정가 3봉 체결권, 랜덤워크 근사 약 60~70%) / `멂 x.x ATR` / `멂 x.x ATR — 체결 비현실`(1.5 ATR 초과, [2-6](#2-6-진입--청산-플레이북)) / `산출 전 — <사유>`(목표 후보 부재는 `산출 전 — 목표 후보 없음`). 현재가(장중)는 `프리뷰`로만 적는다 (2026-11-06, 트레이더 리뷰)

**보조 열** — cRSI · 스토캐스틱 각각 확인/중립/반대와, 그에 따른 보조 배수([2-2](#2-2-판정-위계와-상태-점수판))를 적습니다. 셋업 %에는 넣지 않습니다. 보조 2종은 진입 자격이 아니라 비중과 진입 방식을 정하는 2층이기 때문입니다.

**배정 표기** — 배정표([2](#2-매매-전략-가설))상 현재 국면·위치에 배정된 전략 행에 `(배정)`을 붙이고 근거 셀을 적습니다. 국면·위치 판정 기준은 CEO 지시 대기이므로 `(배정, 추정)`으로 씁니다. 배정되지 않은 전략의 부합률이 낮은 것은 설계상 정상입니다.

**규칙상 진입 성립** = 정식(셋업 부합률 100% + 최종 리스크 ≥ 0.2%) 또는 TIER 성립(셋업 부합률 40% 이상의 구간 + 그 구간의 진입 조건(TIER-60 · TIER-40은 구간 트리거 마감과 시황 판정) + 기술적 리스크 관리 R1~R9 + 절대 금지 X1~X4 미해당 + 최종 리스크 ≥ 0.2%, 검증 변형, [2-5](#구간별-진입-검증-변형-tier)). 리포트는 둘을 구분해 표기한다. 정식 100%는 전 항목 1점(부분 점수 없음. 즉 게이트 `열림` + 트리거 `마감` + 가격 `도달`, 또는 P_max 지정가 체결)이다. 리포트는 이 중 무엇이 남았는지를 사실대로 적고 찬반은 내지 않습니다. 부합률이 높아도 리스크가 0.2% 미만이면 규칙상 진입이 성립하지 않습니다. (2026-11-06, TIER v2 · CEO 결정 · 수학자 설계)

- 셋업 부합률은 **승률이 아닙니다**(미검증). 판독마다 항목별 점수를 로그로 남겨, 뒤의 트리거 발생 여부와 R 결과로 보정합니다.
- 판독 로그에 원점수와 게이팅 후 점수를 모두 남긴다. n ≥ 30 판독 쌍(같은 종목·같은 봉 롱/숏)에서 방향 판별률과 "N봉 안 트리거 발생" AUC를 원점수와 비교하고, 게이팅 점수가 더 낮으면 핵심 항목 정의를 재검토한다. (2026-11-06, 수학자)
- 2026-11-20까지는 구 기준(2026-11-05) 부합률을 괄호로 함께 적습니다. 예: `69% (구 56%)`. 구 기준은 [부록](#부록-구-기준2026-11-05-부합률-산식) 산식으로만 계산합니다 (2026-11-06, 트레이더 리뷰).

**진입한다면의 시나리오** — 전략별로 아래 항목을 모두 적습니다(조건 미형성으로 가격을 못 정하면 "L2 형성 후 산출"처럼 사유를 적습니다).

- 진입 조건(남은 필수·트리거)과 진입가(P_max / 숏은 P_min), 진입 방식([2-6](#2-6-진입--청산-플레이북) (a)/(b))
- 손절가(하드·소프트)
- T1 / T2 / 잔량 분할 비율(%)과 각 R:R, 가중 R:R
- 트레일링 규칙, 즉시 청산 트리거(무효화·진입 전 취소), 시간 손절
- 리스크 비중(사이징 규칙 적용값: 기본 × 보조 배수 × ① 배수 × 구간 배수 = 최종 리스크%, 0.2% 미만이면 그 사실을 표기) (2026-11-06, TIER · CEO 방침 · 수학자 설계 · 트레이더 리뷰)
- 실행(현물 개별주 숏): `실행: 가능 / 제한 / 불가 / 미확인`([2-5](#2-5-공통-리스크--사이징) 숏 실행 가능성). 셋업 부합률에는 넣지 않는다 (2026-11-06, 트레이더 리뷰)

- 구간 열 예: 추세 예측 롱은 셋업 부합률 81%라 TIER-80이다. 구간 트리거 없이 P_max 20,200 지정가를 3봉 둘 수 있고, 시황은 기록만 한다. 역추세 롱과 추세 확정 롱은 전제 게이팅 0%(40% 미만)라 구간이 없다. 게이트가 `⚠ 금지`여도 셋업 부합률이 40% 이상이면 구간은 %대로 정하고 ⚠ 사실을 같은 행에 남긴다 (2026-11-06, TIER v2 · CEO 결정 · 수학자 설계)
- 시나리오 서술 예(추세 예측 롱): B4 2봉 유지와 트리거 마감이 확인되면, 시가 ≤ 20,200일 때 (a) 시가 진입, 아니면 (b) 20,200 지정가 3봉. 하드 손절 19,900. T1 20,800에서 1/3 청산 후 본전 이동, T2 21,400에서 1/3. 잔량은 T/D 골든 전에는 `DEMA 전환` 자홍 마감, 골든 후에는 `데드교차` 가격 아래 마감 시 청산. 진입 전 취소는 `Sonar 교차` 자홍 복귀 또는 저가 < L. 시간 손절 10봉(판정 TF ① 역행이면 5봉). 리스크 0.5%(가점 3) × 0.75(보조 둘 다 중립) × 1.0(① 순행 · 순행, 청산 정상) = 0.375%(정식 100% 기준) (2026-11-06, 문구 정합화). 지금(81%) 들어가면 TIER-80: B4 2봉과 트리거를 기다리지 않고 20,200 지정가 3봉, 0.375% × 0.75 = 0.28% (2026-11-06, TIER v2 · CEO 결정 · 수학자 설계).

**간단 리포트** — CEO가 "간단 리포트"를 요청하면 이 형식만 씁니다. 판독 절차·채점은 전체 리포트와 같고 출력만 줄입니다. (2026-11-06, 트레이더 리뷰)

- 형식: 세 전략(추세 확정·추세 예측·역추세)을 모두 행으로 쓴다. 열 = 전략 | 셋업 부합률 | 구간 | 진입가 | 손절 | 익절(잔량) | 리스크 비중. 리스크 비중 열은 구간 배수 반영 값 (2026-11-06, TIER · CEO 방침 · 수학자 설계 · 트레이더 리뷰). 익절은 1차·2차·잔량을 별도 행으로 쓰고(같은 전략의 2·3번째 행은 다른 칸을 비움) HTML 태그는 쓰지 않는다. 표 아래 전략별 초보자용 쉬운 설명 1~2문장.

## 3. Claude Code ↔ TradingView MCP 연결

Claude Code가 TradingView 데이터를 읽게 하는 MCP는 **두 종류**이며 용도가 다릅니다. 시장 데이터 조회는 공식 MCP, **지금 데스크탑에 열린 차트**(지표 값·테이블·스크린샷)를 읽으려면 Desktop MCP가 필요합니다.

| 구분 | 공식 TradingView MCP | TradingView Desktop MCP |
| --- | --- | --- |
| 이름 | `mcp-tradingview` | `tradingview-desktop` (커뮤니티·비공식) |
| 할 수 있는 것 | 시장 데이터·스크리너·기술적 분석·뉴스·관심종목·알림 | 실행 중인 데스크탑 앱의 차트 상태·탭·지표 값·테이블·스크린샷·Pine Script 편집/컴파일 |
| 열린 차트 읽기 | **불가** | 가능 |
| 연결 방식 | 원격 URL + TradingView OAuth | 로컬 디버그 연결 (맥) |
| 요구 사항 | TradingView Essential 이상 유료 플랜(체험판 불가), API Key 불필요 | Node.js 20.19 이상 |

### 3-1. 공식 TradingView MCP

```bash
claude mcp add --transport http --scope user mcp-tradingview https://mcp.tradingview.com/mcp
```

1. `claude` 실행 → `/mcp` → `mcp-tradingview` 선택 → **Authenticate**
2. 브라우저에서 TradingView 로그인 → 권한 승인
3. 확인: `claude mcp list` 또는 Claude Code 안에서 `/mcp`

### 3-2. TradingView Desktop MCP

```bash
node -v                                              # 20.19 이상인지 확인
npx -y tradingview-desktop-mcp launch --restart      # 현재 레이아웃을 저장한 뒤 실행 — 디버그 모드로 앱 재시작
claude mcp add --scope user tradingview-desktop -- npx -y tradingview-desktop-mcp
npx -y tradingview-desktop-mcp doctor                # 차트 탭이 활성인 상태에서 점검
```

등록 후 **Claude Code를 재실행**하면 사용할 수 있습니다.

> ⚠️ 비공식 프로젝트라 TradingView 앱 업데이트에 따라 동작이 달라질 수 있습니다. 로컬 디버깅 포트는 외부(네트워크·포트포워딩)에 **노출하지 마세요.**

**예시 프롬프트**

```text
현재 열린 차트의 종목·타임프레임·지표를 읽고 분석해줘. 차트는 수정하지 마.
```

차트를 바꿀 수 있는 도구(지표 추가·삭제, 입력값 변경, 종목·타임프레임 변경 등)도 포함되어 있으므로, 분석만 원할 때는 위처럼 **"수정하지 마"를 명시**합니다.
