# MACD 크로스 조기 경보 (Cross Warning)

트레이딩뷰용 Pine Script 보조지표 설명서입니다.

대상 스크립트:
- [`macd-cross-warning.pine`](./macd-cross-warning.pine)

이 지표는 CM MACD MTF V2.1을 베이스로, 표준 `MACD / Signal / Histogram` 구조 위에 **크로스 조기 경보**(골든/데드 크로스 임박 감지)와 **삼중 스토캐스틱 스타일 배경**을 얹은 버전입니다. 크로스가 "이미 난 뒤"가 아니라 "나기 직전 수렴 구간"을 미리 배경색으로 보여주어, 관찰 준비를 앞당기는 데 목적이 있습니다.

> 이전 버전(`macd-divergence-tracker.pine`, 가격 MA 기울기 vs 히스토그램 방향 다이버전스)을 대체합니다. 다이버전스 색 로직은 제거되었고, 대신 크로스 조기 경보 + 배경 방식으로 재작성되었습니다.

## 현재 소스 기준으로 보이는 것

| 요소 | 현재 표시 방식 |
| --- | --- |
| MACD 선 | `Fast Length = 12`, `Slow Length = 26` EMA 차이. `Show Trend`가 켜져 있으면 방향에 따라 초록/빨강으로 색이 바뀝니다. |
| Signal 선 | `Signal Smoothing = 9` EMA. 실제 크로스 타이밍 판단 기준선입니다. |
| Histogram | `MACD - Signal`. 0선 대비 위/아래, 커지는지/줄어드는지에 따라 4색으로 표시됩니다. |
| 크로스 원(dots) | MACD와 Signal의 실제 교차 시점을 원으로 표시합니다(옵션). |
| 골든 크로스 주의 배경 | 히스토그램이 0 아래에서 위로 수렴 중이면 초록 배경(`#2E7D32`, 투명도 입력값·기본 60). |
| 데드 크로스 주의 배경 | 히스토그램이 0 위에서 아래로 수렴 중이면 빨강 배경(`#C62828`, 투명도 입력값·기본 60). |

참고:
- 기본 MACD는 CM V2.1 표준값 `Fast 12 / Slow 26 / Signal 9`로 되어 있습니다(이전 버전의 9/20/7과 다릅니다).
- `Source`와 `Indicator TimeFrame`은 MACD/Signal/Histogram 및 조기 경보 ATR 정규화 계산에 함께 적용됩니다.
- `Histogram Scale`은 히스토그램의 시각 크기만 바꾸며 계산·경보 로직에는 영향을 주지 않습니다.

## 크로스 조기 경보 — 핵심 아이디어

일반 MACD의 크로스 원(dots)은 **교차가 이미 일어난 봉**에 찍힙니다. 조기 경보는 그보다 앞서, **히스토그램이 0선으로 수렴하는 과정**을 포착해 "크로스가 임박했을 수 있다"를 배경색으로 미리 알립니다.

- **골든 크로스 주의(초록 배경)**: 히스토그램이 아직 0 아래(약세)지만, 최근 여러 봉 연속으로 0을 향해 올라오고, 0에 충분히 가까워졌을 때.
- **데드 크로스 주의(빨강 배경)**: 히스토그램이 아직 0 위(강세)지만, 최근 여러 봉 연속으로 0을 향해 내려오고, 0에 충분히 가까워졌을 때.

두 조건은 히스토그램의 부호(0 아래/위)로 갈리므로 **동시에 켜지지 않습니다**(상호배타).

## 조기 경보 조건식 (내부 로직)

`hist = MACD - Signal`, `atr = ATR(warn_atrLen)` (둘 다 지표 TF·`lookahead_off` 기준)이라 할 때:

- 골든 주의: `hist < 0` **그리고** `hist가 warn_N봉 연속 상승(0으로 수렴)` **그리고** `|hist| < warn_k * atr` **그리고** (가속도 OFF 이거나 히스토그램 2차 차분 > 0) **그리고** (지속 필터 OFF 이거나 데드 상태가 M봉 이상 유지)
- 데드 주의: `hist > 0` **그리고** `hist가 warn_N봉 연속 하락(0으로 수렴)` **그리고** `|hist| < warn_k * atr` **그리고** (가속도 OFF 이거나 히스토그램 2차 차분 < 0) **그리고** (지속 필터 OFF 이거나 골든 상태가 M봉 이상 유지)

포인트:
- **ATR 정규화**: 근접 판정을 고정값이 아니라 `warn_k * ATR`로 합니다. 심볼·타임프레임이 달라도 같은 파라미터가 통하도록(이식성) 하기 위함입니다.
- **N봉 연속 수렴**: `is_rising / is_falling` 헬퍼가 히스토그램이 N봉 동안 실제로 한 방향(0쪽)으로 움직였는지 확인합니다. 한 봉 반짝이 아니라 방향성 있는 수렴만 잡습니다.
- **가속도 조건(선택)**: 켜면 히스토그램 2차 차분(수렴이 가속 중인지) 조건을 추가로 요구해 경보가 더 엄격해집니다.
- **상태 지속 필터(선택, 기본 ON)**: 반전을 경보하기 전에 **반대 상태가 최소 M봉 유지**됐는지 확인합니다. 골든 주의는 직전 데드 상태(`hist < 0`)가, 데드 주의는 직전 골든 상태(`hist > 0`)가 M봉 이상 이어진 뒤에만 켜집니다. 확정봉 기준 `ta.barssince(hist[1] >= 0) >= M`(데드 지속) / `ta.barssince(hist[1] <= 0) >= M`(골든 지속)으로 판정하며, 경계 등호(`>= 0` / `<= 0`)는 골든/데드 주의의 부호 규약(`hist < 0` / `hist > 0`)과 대칭입니다. **갓 전환된 직후(방금 크로스가 난 자리에서 바로 반대 방향으로 되돌아가는 위플로)를 걸러내는 것이 목적**입니다. 토글 OFF면 이 조건이 항상 통과되어 기존 동작이 그대로 복원됩니다.

## 배경색 로직 (삼중 스토캐스틱과 동일 방식)

`TRIPLE-STOCH/triple-stochastic-wave.pine`의 웨이브 배경과 **동일한 팔레트·방식**을 씁니다.

```
bgcolor(show_warn_bg and golden_warn ? color.new(#2E7D32, warn_bg_transp) : na, title="Golden Cross Warning", editable=true)
bgcolor(show_warn_bg and dead_warn   ? color.new(#C62828, warn_bg_transp) : na, title="Dead Cross Warning",   editable=true)
```

- 색: 골든 주의 = 녹 `#2E7D32`, 데드 주의 = 적 `#C62828` (삼중 스토와 동일).
- 투명도는 `경보 배경 투명도` 입력으로 조절(기본 60, 0=불투명~100=완전투명), `editable=true`, `title` 명시.
- 상호배타(부호로 갈림) → 두 배경이 동시에 뜨지 않습니다.
- `조기 경보 배경 표시` 토글로 on/off (기본 ON).

## 리페인팅 안전

- 모든 MTF `request.security` 호출에 **`lookahead=barmerge.lookahead_off`**를 적용해 미래참조를 차단합니다.
- 조기 경보 판정(`golden_warn / dead_warn`)은 **확정봉 기준**입니다. 히스토그램·ATR을 직전 확정봉(`[1]`) 값으로 읽어, 상위 TF의 미마감봉에서 경보가 켜졌다 꺼졌다 하는 점멸(리페인팅)을 막습니다.
  - 대가로 배경/경보가 **한 봉 지연**됩니다. 이는 "확정봉만 신뢰"라는 저장소 원칙에 따른 의도된 트레이드오프입니다.
- 히스토그램 색(4색)은 시각 전용이며 경보·신호 판정에 쓰이지 않습니다.

## 입력 정리

### 기본 설정 (CM V2.1)
| 설정 | 기본값 | 의미 |
| --- | --- | --- |
| `Indicator TimeFrame` | 현재 TF | MACD·ATR 계산 기준 TF. 상위 TF 지정 시 확정봉만 신뢰. |
| `Source` | close | MACD 계산 기준가. |
| `Fast Length` / `Slow Length` | 12 / 26 | 빠른·느린 EMA 길이. |
| `Signal Smoothing` | 9 | 시그널 EMA 길이. |
| `Oscillator / Signal MA Type` | EMA / EMA | SMA/EMA 선택. |

### 크로스 조기 경보 (신규)
| 설정 | 기본값 | 의미 |
| --- | --- | --- |
| `조기 경보 배경 표시` | ON | 골든/데드 주의 배경 on/off. |
| `조기경보 수렴 봉수 (warn_N)` | 3 | 히스토그램이 0으로 몇 봉 연속 수렴해야 경보로 볼지. 클수록 드물고 늦음. |
| `조기경보 근접 ATR 배수 (warn_k)` | 0.15 | `|hist| < warn_k * ATR` 근접 임계. 클수록 경보가 더 자주(더 이르게) 뜸. |
| `조기경보 ATR 길이 (warn_atrLen)` | 14 | 근접 정규화에 쓰는 ATR 길이. |
| `가속도 조건 (warn_accel)` | OFF | ON이면 2차 차분(수렴 가속) 조건 추가 → 더 엄격. |
| `경보 배경 투명도 (warn_bg_transp)` | 60 | 골든/데드 주의 배경 투명도. 0=불투명, 100=완전투명. |
| `상태 지속 필터 (warn_persist_on)` | ON | 반대 상태가 M봉 이상 유지된 뒤 반전 임박 시에만 경보(갓 전환 직후 노이즈 컷). OFF면 현재 상태만 확인(기존 동작). |
| `상태 지속 최소 봉수 M (warn_persist_M)` | 6 | 반대 상태(hist 부호)가 최소 몇 봉 유지돼야 경보 허용. `warn_N`보다 커야 의미가 있음. |

## 알림

- CM V2.1 4종: `MACD Cross Up`, `MACD Cross Dn`, `MACD Cross Up & > 0`, `MACD Cross Dn & < 0` (확정봉 종가 기준 `alert()`).
- 신규 2종(`alertcondition`): `Golden Cross Warning`, `Dead Cross Warning` — 조기 경보 배경과 같은 조건.

## 주의사항

- **조기 경보는 "관찰 준비" 신호이지 진입 트리거가 아닙니다.** 히스토그램이 0에 수렴했다가 크로스로 이어지지 않고 되돌아가는 경우(위플로/오탐)가 있습니다. 특히 횡보·저변동 구간에서 히스토그램이 0 근처를 오갈 때 배경이 자주 깜빡일 수 있습니다.
- `warn_N`·`warn_k`·`가속도 조건`은 이 오탐과 조기성 사이의 트레이드오프를 조절합니다. `warn_k`를 키우면 더 이르게(오탐↑), 줄이면 더 늦게(오탐↓) 뜹니다.
- `상태 지속 필터`(기본 ON)는 **갓 전환 직후의 위플로(방금 크로스한 자리에서 곧바로 되돌아가는 노이즈)를 걸러내 오탐을 줄입니다**. 대신 반대 상태가 M봉 미만으로 짧게 유지된 뒤 빠르게 반전하는 국면에서는 경보를 놓칠 수 있습니다(미탐↑). `M`을 키우면 더 오래 유지된 추세의 반전만 잡아 엄격해지고, 줄이면 관대해집니다. 이 트레이드오프의 유효성은 아래와 같이 **백테스트 전 미검증 가설**입니다.
- **파라미터 기본값과 조기 경보의 유효성은 백테스트 전 미검증 가설입니다.** 실제 매매 반영 전 알고리즘 수학자의 통계 검증(승률·엣지·과최적화 여부)이 필요합니다.
- MTF로 상위 TF를 쓰면 확정봉 기준이라도 현재 차트 봉과 계산 봉의 체감 시점이 다를 수 있습니다.
- 단일 신호를 믿지 말고 이치모쿠(메인)·상태 테이블·다른 보조지표와의 정렬을 함께 확인하세요(저장소 교차 검증 원칙).
