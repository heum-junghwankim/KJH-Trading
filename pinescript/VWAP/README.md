# Auto VWAP

가격 차트 위에 그리는 지표입니다. 대상 스크립트: [`auto-vwap.pine`](./auto-vwap.pine) (Pine Script v6)

## 한 줄 정의

최근 20봉 동안 거래된 물량의 평균 단가(VWAP)를 기준으로, 지금 가격이 그 평균에서 얼마나 멀리 나왔는지와 이동평균들이 어느 방향으로 정렬됐는지를 한 화면에 모은 지표입니다.

## 차트에서 읽는 법

| 요소 | 모양 (기본값) | 뜻 |
| --- | --- | --- |
| 밴드 세트 A | 흰 대시, 최근 20봉 VWAP의 ±2σ | 평균에서 크게 벗어난 거리. 강한 추세에서는 밖에 오래 머뭄 |
| 밴드 세트 B | 회색 점, 최근 50봉 VWAP의 ±2σ | 더 긴 기준의 같은 거리 (표시 전용) |
| VWAP 중앙선 | 흰 대시, **기본 숨김** | 평균 단가 |
| 리본 | EMA 노랑 · DEMA 하늘 · TEMA 분홍 (종가, 길이 20) | 빠른 순서 TEMA > DEMA > EMA |
| 거래량 가중선 | 50선 주황 `#FF6D00` · 100선 파랑 · 200선 보라 | 단기·중기·장기 기준선 |
| 배경 (Sonar) | 파랑 / 녹 / 빨강 / 주황, 투명도 85 | 아래 "배경색" |
| 캔들 색 | 붉은 = 과매수 극단, 파랑 = 과매도 극단 | 아래 "극단 캔들" |
| 원 마커 | 하늘색(봉 아래) / 분홍(봉 위) | Williams %R 1봉 다이버전스 |
| 상태 테이블 | 우측 상단, 5개 섹션 | 아래 "상태 테이블" |

**배경색** — Sonar = EMA(종가,20) − 9봉 전 EMA(종가,20), Signal = EMA(Sonar,9). Sonar > Signal = 골든, < = 데드(같으면 직전 유지).
골든 + 상승 밴드워킹 = 파랑 `#2196F3`, 그 밖의 골든 = 녹 `#2E7D32`, 데드 + 하락 밴드워킹 = 빨강 `#C62828`, 그 밖의 데드 = 주황 `#FF6D00`.
골든은 "모멘텀이 자기 평균보다 좋아짐"이지 "상승 추세"가 아닙니다. 하락이 둔화되기만 해도 녹색이 켜집니다.

**극단 캔들** — 과매수(붉은) = cRSI(주기 20 기준, RSI 길이 10) ≥ 70 이면서 고가가 볼린저(SMA20, 2σ) 상단을 캔들 길이(고가−저가)의 30% 이상 넘은 봉. 과매도(파랑)는 대칭(≤ 30, 저가가 하단 아래).
한 번 켜지면 이격도(종가 ÷ SMA20)가 중립으로 돌아올 때까지 다음 봉들도 같은 색입니다. cRSI 판정은 cRSI 지표의 동적 밴드가 아니라 고정 70/30입니다.

**%R 원** — 강세 = 직전 봉 %R(20) < −80, 이번 봉 종가 하락, %R 상승. 약세 = 직전 %R > −20, 종가 상승, %R 하락. 피벗 기반이 아닌 1봉 비교입니다.

## 상태 테이블

레이아웃: `가로형`(기본, 10열 × 5행) / `세로형`(2열 × 21행). 섹션 제목 괄호 = 그 섹션의 기준봉.
`완성봉` = 가장 최근 확정봉 기준, 형성 중 고정, %는 그 봉 종가 대비. `실시간봉` = 형성 중인 봉 기준, 틱마다 갱신, %는 현재가 대비.
색: 청록 `#0E9C8A` = 상승 쪽, 자홍 `#C2185B` = 하락 쪽, 회색 = 중립·데이터 부족.

**① 추세 확인 (완성봉)** — 이동평균 기준으로 추세가 이미 정해졌나? (후행)

| 행 | 비교 | 값 |
| --- | --- | --- |
| `단기추세` | VWMA 20(차트에 안 그림) vs 50 | 크로스 봉: `골든 크로스`/`데드 크로스`. 그 외: `(강한/약한) 상승·하락 (+x.x% \| N봉)` — %는 크로스 이후 빠른 선 변화율, N은 크로스 후 봉 수 |
| `중기추세` | VWMA 50 vs 100 | 같은 형식 |
| `장기추세` | VWMA 100 vs 200 | 같은 형식 (200봉 미만이면 `-`) |

강약: 크로스 후 5봉 동안은 `상승`/`하락`만. 그 뒤 두 선 간격이 5봉 전보다 ATR14 × 0.25 넘게 벌어지면 `강한`(선명), 그만큼 좁아지거나 간격 ≤ 종가의 4%(벌어지는 중이 아닐 때)면 `약한`(옅음), 그 밖은 `상승`/`하락`(중간 톤).

**② 기울기 전환가 (실시간봉)** — 다음 봉이 얼마에 마감하면 리본선이 꺾이나?

| 행 | 값 예시 | 셀 색 (현재 상태) |
| --- | --- | --- |
| `TEMA 전환` | `상승전환 : 가격 (±%)` / `하락전환 : …` | TEMA 상승 중 청록 / 하락 중 자홍 |
| `DEMA 전환` | 같은 형식 | DEMA 상승 중 청록 / 하락 중 자홍 |
| `정배열 전환` | `정배열 : 가격 (±%)`, 이미 정배열이면 `-` | 정배열 청록 / 역배열 자홍 / 중립 회색 |
| `역배열 전환` | `역배열 : 가격 (±%)`, 이미 역배열이면 `-` | 위와 같음 |

정배열 = 세 선의 **1봉 기울기**가 TEMA > DEMA > EMA (선 위치 순서가 아님). 노이즈 필터는 `밴드 배경 필터`(기본 `정규화 갭`). 배열 행 가격은 근사값입니다.

**③ 교차 전환가 (실시간봉)** — 다음 봉이 얼마에 마감하면 두 선이 교차하나?

| 행 | 값 예시 | 셀 색 |
| --- | --- | --- |
| `Sonar 교차` | `하락교차 : 가격 (±%)` / `상승교차 : …` | Sonar 골든 청록 / 데드 자홍 / 준비 중 회색 |
| `T/D 교차` | `골든교차 : 가격 (±%)` / `데드교차 : …` | TEMA > DEMA 청록 / < 자홍. 흐린 톤(`#6E8F72`, `#A57A7A`) = 같은 상태지만 간격이 줄어드는 중 |

②③ 공통: 가격은 틱 단위로 맞춤(상승 조건은 올림, 하락 조건은 내림). 0 이하이거나 ±50% 초과면 `도달불가`, 계산 전이면 `-`, `리본 소스`가 `종가`가 아니면 Sonar 외 행은 `소스≠종가`.

**④ 변동성 임계가 (실시간봉)** — 밴드를 타고 달리는 중인가, 평균에서 너무 멀어졌나?

| 행 | 값 | 셀 색 |
| --- | --- | --- |
| `상승확장(20)` | 횡보면 `상승 : 가격`(상승 워킹이 되는 다음 봉 종가), 상승 워킹이면 `횡보 : 가격`(풀리는 종가), 하락 워킹이면 `-` | 상승 워킹 청록 / 하락 워킹 자홍 / 횡보 회색 |
| `하락확장(20)` | 위와 대칭 | 위와 같음 |
| `이격도 (20)` | `값 (중립 / 되돌림 주의 / 되돌림 확실)`, 값 = 종가 ÷ SMA20 × 100 | 위쪽 확실 빨강, 아래쪽 확실 초록, 주의는 흐린 빨강/녹, 중립 회색 |
| `되돌림 가격` | 이격도가 중립으로 돌아오는 경계 가격 `(±%)`, 중립이면 `-` | 회색 |

밴드워킹: 종가 > 20봉 VWAP의 +1σ 이고, VWAP의 5봉 변화가 밴드(±2σ) 폭의 3%를 넘는 상승이거나(평탄하면 밴드폭이 5봉 전보다 넓을 때) 상승 워킹. 단, 종가 > +2σ 이면서 밴드가 넓어지지 않고 VWAP가 평탄·하락이면 제외. 하락은 대칭.
확장 행 가격은 수치 탐색 근사이며, 다음 봉 거래량 = 기준봉 거래량, 다음 봉 평균가(hlc3) = 종가로 가정합니다.
이격도: 고정 기준 ±10%, 적응 기준 = 최근 50봉 이격도 표준편차 × 1.5. 하나 넘으면 `주의`, 둘 다 넘으면 `확실`. `되돌림 가격` = 현재 SMA20 × (1 ± min(10%, 1.5σ)). SMA20도 움직이므로 도달 보장은 없습니다.

**⑤ 지지·저항 임계가 (완성봉)** — 50/100/200선이 지금 지지인가 저항인가?

| 행 | 값 | 셀 색 |
| --- | --- | --- |
| `50선` / `100선` / `200선` | 선 가격 `(종가 대비 ±%)` — 선이 위면 `+` | 지지 녹 / 저항 빨강 / 판정 없이 위 흐린 녹 `#6E8F72` / 아래 흐린 빨강 `#A57A7A` / 선 없음 회색 |

판정: 각 선 ± 1.0 × 거래량 가중 표준편차를 판정 밴드로 두고, 그 밴드의 20~60%(변동성이 클수록 좁게) 안에 종가가 있거나 꼬리가 닿으면 지지(선 위) 또는 저항(선 아래)입니다.

기간·임계값은 전략 파라미터입니다. 바꾸려면 알고리즘 수학자 검토를 먼저 받습니다.

## 잘 맞는 국면 / 약한 국면

- 추세 구간: 리본·VWMA 정렬, 밴드워킹, 추세 확인 행이 방향을 일관되게 보여줍니다.
- 횡보 구간: 리본 기울기와 Sonar가 자주 뒤집혀 ②③ 값과 배경색이 계속 바뀝니다. 후행 지표인 ①은 늦게 반응합니다.
- 위 성향은 일반론이며 펀드 데이터로 검증하지 않았습니다.

## 초보가 흔히 하는 실수

- 녹색 배경 = 상승 추세로 읽기. Sonar 골든은 모멘텀 개선이며 하락 둔화에서도 켜집니다.
- 실시간봉 값으로 판단하기. ②③④ 섹션, 배경, 캔들색, %R 원은 형성 중 봉에서 켜졌다 꺼질 수 있습니다. 마감 후 확인합니다.
- ②③④의 가격을 "이번 봉" 목표로 읽기. 실시간봉 모드에서도 **다음 봉 종가** 조건입니다.
- 밴드 밖 = 반전으로 읽기. 강한 추세에서는 밴드 밖이나 경계에 오래 머뭅니다.

## 주의

- 거래량 데이터가 없으면 동작하지 않습니다(`runtime.error`).
- `Recent Bars`는 봉 수 기준이라 타임프레임을 바꾸면 의미가 달라집니다.
- `request.security`·`lookahead`를 쓰지 않아 미래참조는 없습니다. 과거 봉은 마감 후 바뀌지 않습니다.
- 이 지표는 매매 신호를 내지 않습니다. 진입·청산 규칙은 아직 없습니다.
