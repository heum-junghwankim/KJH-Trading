# Abnormal Candle + Williams %R (비정상 캔들 + 윌리엄스 %R)

TradingView Pine Script v6 오버레이 지표. **Auto VWAP**(`pinescript/VWAP/auto-vwap.pine`)에서 **비정상 매수/매도 캔들 페인팅**과 **윌리엄스 %R 다이버전스 원 마커** 두 기능만 떼어낸 **경량 독립 지표**다.

- 파일: [`abnormal-candle-wpr.pine`](./abnormal-candle-wpr.pine)
- 타입: `indicator(overlay=true, max_bars_back=1000)` — 가격 차트 위에 **캔들 몸통색**과 **원 마커**로만 표시.
- 역할: Auto VWAP의 밴드·리본·상태 테이블 없이 **극단 구간(비정상 캔들)** 과 **모멘텀 엇갈림(%R 다이버전스)** 만 깔끔하게 보고 싶을 때 쓴다. 이치모쿠(메인) + 테이블 + 보조지표 정렬을 확인하는 **교차 검증용 보조 도구**이며, **단독 진입 신호가 아니다.**

> ⚠️ 이 지표는 Auto VWAP에서 **분리 이식**한 것이다. 두 기능의 입력 기본값·산식·마커 스타일은 원본과 **동일**하게 유지했다. 따라서 같은 차트에 Auto VWAP과 이 지표를 함께 올리면 **캔들색·원 마커가 동일한 봉에 중복 표시**된다. 둘 중 하나만 쓰는 것을 권장한다.

---

## 1. 화면에 그려지는 것 (전부 2가지)

| 요소 | 표시 방식 | 의미 |
| --- | --- | --- |
| 비정상 매도 캔들 | 해당 봉의 **캔들 몸통색 = 파랑**(`color.blue`) | 과매도 극단 — cRSI 과매도 + 볼린저 **하단** 이탈 |
| 비정상 매수 캔들 | 해당 봉의 **캔들 몸통색 = 붉은색**(`#E53935`) | 과매수 극단 — cRSI 과매수 + 볼린저 **상단** 돌파 |
| %R 강세 다이버전스 | 봉 **아래**(`belowbar`) **하늘색 원**(`#81D4FA`, `size.tiny`) | 과매도 진입 후 종가↓ · %R↑ (매수 쪽 엇갈림) |
| %R 약세 다이버전스 | 봉 **위**(`abovebar`) **분홍 원**(`#FF1493`, `size.tiny`) | 과매수 진입 후 종가↑ · %R↓ (매도 쪽 엇갈림) |

비정상 구간이 **아닌** 봉은 캔들색을 건드리지 않는다(`barcolor(na)` → 차트 기본 캔들색 유지).

**이 지표에는 라인·밴드·배경·테이블이 하나도 없다.** VWAP선, VWAP 밴드, 지수 추세 리본, VWMA, 이격도 표시, 되돌림 가격, 기울기 정렬 삼각형, 변곡 마커, 스윕/청산선, 상태 테이블은 **전부 이식 대상에서 제외**했다.

## 2. 비정상 매수/매도 (캔들 몸통색)

### 2-1. 판정

두 조건이 **동시에** 성립할 때만 비정상으로 본다.

1. **cRSI(도미넌트 사이클 RSI) 절대 과매수/과매도**
   - `abnCycleLen = max(1, int(기준길이 / 2))` 길이의 RSI 원값을 구한 뒤, Vibration 기반 토크(`2/(Vibration+1)`)와 위상 지연(`int((Vibration−1)/2)`)으로 평활한 값이 cRSI다.
   - cRSI ≥ `비정상 절대 과매수`(기본 70) → 과매수 / cRSI ≤ `비정상 절대 과매도`(기본 30) → 과매도.
2. **볼린저 밴드 이탈 (고가/저가 기준)**
   - `basis = SMA(close, 기준길이)`, `dev = STDEV(close, 기준길이) × 배수`.
   - 과매수 쪽: `high − upper`의 초과폭 ÷ 캔들 범위(`high−low`, 최소 `mintick`) ≥ `밴드 초과 비율`(기본 0.3).
   - 과매도 쪽: `lower − low`의 이탈폭 ÷ 캔들 범위 ≥ 같은 비율.

**매핑 주의:** 이 저장소의 용어에서 **비정상 "매수" = 과매수(고점 경고, 붉은색)**, **비정상 "매도" = 과매도(저점 경고, 파랑)** 이다. 캔들 색은 "지금 그 방향으로 사라/팔아라"가 아니라 **"그 방향으로 과하게 쏠렸다"** 는 경고다.

### 2-2. 상태 래치와 해제 조건

비정상 판정은 봉 단위로 끝나지 않고 **상태(`abnCandleState`)로 래치**된다. 한 번 비정상이 뜨면 **이격도가 중립으로 복귀할 때까지** 색이 유지된다.

- 이격도 = `종가 ÷ 이평 × 100`. 고정 임계(±%)와 적응형(σ 배수) 두 기준 중 **어느 것도 걸리지 않으면 중립** → 래치 리셋(색 해제).
- 그래서 **이격도 입력 5개가 이 지표에 함께 들어있다.** 이격도 값 자체는 **화면에 그리지 않는다** — 오직 캔들색이 언제 꺼지는지를 결정할 뿐이다.

### 2-3. 리페인팅 특성

- 상태 갱신(`abnCandleState`·기준점 스냅샷·반등 감시)은 **확정봉(`barstate.isconfirmed`)에서만** 일어난다. 형성 중인 현재봉이 래치를 흔들지 않는다.
- 다만 **형성 중인 현재봉의 캔들색**은 그 봉의 `close/high/low`가 계속 변하므로 봉이 닫힐 때까지 켜졌다 꺼졌다 할 수 있다(원본 Auto VWAP과 동일한 거동). **확정된 과거봉은 바뀌지 않는다.**
- 미래 참조(`request.security`의 lookahead 등)는 **없다.**

### 2-4. 화면에 없지만 계산되는 것 — 반등 감시(`abnWatch`)

원본과의 동일성을 유지하기 위해 **반등 감시** 로직(비정상 캔들 이후 ATR 대비 되돌림 + RSI 이동 제한 게이트)을 그대로 포함했다. 다만 **원본 Auto VWAP도 이 상태를 화면에 표시하지 않으므로**, 이 지표에서도 표시하지 않는다. `비정상 반등 감시 ATR 배수`·`비정상 RSI 이동 제한` 두 입력은 이 계산에만 쓰이며 **캔들색에는 영향이 없다.**

## 3. 윌리엄스 %R 다이버전스 (원 마커)

`ta.wpr(길이)`는 −100~0 범위의 오실레이터다. 오버레이 지표에는 라인을 그릴 수 없으므로, **다이버전스가 발생한 봉에 원 마커만** 찍는다.

- **강세(매수) 다이버전스**: `직전 봉 %R < 하단 밴드(−80)` **AND** `종가 < 직전 종가` **AND** `%R > 직전 %R`
  → 가격은 더 내려갔는데 %R은 올라옴 = 하락 모멘텀 소진 조짐. 봉 **아래** 하늘색 원.
- **약세(매도) 다이버전스**: `직전 봉 %R > 상단 밴드(−20)` **AND** `종가 > 직전 종가` **AND** `%R < 직전 %R`
  → 가격은 더 올라갔는데 %R은 내려옴 = 상승 모멘텀 소진 조짐. 봉 **위** 분홍 원.

**리페인팅 없음.** `close[1]`·`wpr[1]`·`wpr` 모두 확정/과거 참조이며 미래 참조가 없다. 다만 **형성 중인 현재봉**에서는 종가가 확정될 때까지 마커가 나타났다 사라질 수 있다(모든 종가 기반 지표의 공통 성질). 봉 마감 후 확정된다.

---

## 4. 입력 파라미터

입력 기본값·옵션·라벨·툴팁은 **Auto VWAP 원본과 동일**하다. 이 지표를 만들면서 신규 파라미터를 추가하거나 기본값을 바꾼 것은 **없다.**

### 4-1. 윌리엄스 %R 다이버전스

| 입력 | 변수 | 기본값 | 설명 |
| --- | --- | --- | --- |
| %R 다이버전스 원 표시 | `showWprDiv` | `true` | 원 마커 표시 토글 |
| 윌리엄스 %R 길이 | `wprLen` | `14` | `ta.wpr` 계산 기간(표준 14) |
| %R 하단 밴드 | `wprLower` | `-80` | 강세 다이버전스 진입 임계(과매도) |
| %R 상단 밴드 | `wprUpper` | `-20` | 약세 다이버전스 진입 임계(과매수) |
| %R 강세 다이버전스 원 색(매수) | `wprBullColor` | `#81D4FA` | 봉 아래 원 색 |
| %R 약세 다이버전스 원 색(매도) | `wprBearColor` | `#FF1493` | 봉 위 원 색 |

### 4-2. 비정상 매수/매도

| 입력 | 변수 | 기본값 | 설명 |
| --- | --- | --- | --- |
| 비정상 캔들 cRSI Vibration | `abnVibration` | `10` | cRSI 평활 토크·위상 지연 기준 |
| 비정상 절대 과매수 | `abnOB` | `70.0` | cRSI 과매수 임계 |
| 비정상 절대 과매도 | `abnOS` | `30.0` | cRSI 과매도 임계 |
| 비정상 기준 길이(볼린저 등) | `abnBbLen` | `20` | 볼린저·cRSI 사이클(÷2)·RSI·ATR·추적 lookback 공통 기준 길이 |
| 비정상 볼린저 배수 | `abnBbMult` | `2.0` | 밴드 표준편차 배수 |
| 비정상 밴드 초과 비율(고저 기준) | `abnBodyRatio` | `0.3` | (밴드 초과폭 ÷ 캔들 범위) 최소 비율 |
| 비정상 반등 감시 ATR 배수 | `abnAtrMult` | `1.5` | 반등 감시 전용(**화면 표시 없음**) |
| 비정상 RSI 이동 제한 | `abnRsiMoveLimit` | `15.0` | 반등 감시 전용(**화면 표시 없음**) |
| 비정상 매수/매도 캔들색 표시 | `abnShowBg` | `true` | 캔들 몸통색 표시 토글 |
| 비정상 매도 캔들색(파랑) | `abnSellBgColor` | `color.blue` | 과매도 극단 봉 색 |
| 비정상 매수 캔들색(붉은색) | `abnBuyBgColor` | `#E53935` | 과매수 극단 봉 색 |

### 4-3. 이격도 (표시 없음 — 캔들색 해제 조건 전용)

| 입력 | 변수 | 기본값 | 설명 |
| --- | --- | --- | --- |
| 이격도 MA 종류 | `disparityMaType` | `"SMA"` | `SMA`/`EMA`/`WMA`/`VWMA` |
| 이격도 MA 길이 | `disparityMaLen` | `20` | 기준 이평 길이 |
| 이격도 임계(±%, 고정) | `disparityThreshold` | `10.0` | 고정 임계 |
| 이격도 통계 구간(적응형) | `disparityStatLen` | `50` | σ 계산 구간 |
| 이격도 통계 시그마 배수 | `disparityStatMult` | `1.5` | 적응형 임계 배수 |

> ⚠️ 위 표의 **기간·임계·배수는 전부 전략 파라미터**다. 값을 바꾸면 신호 빈도와 성격이 바뀌므로 **전략 변경**으로 간주한다. 변경은 본부장·알고리즘 수학자 검토 대상이며, 과최적화 리스크를 함께 검토해야 한다. 색상·토글은 표시용이라 자유롭게 조정해도 된다.

## 5. 사용법 (교차 검증 관점)

1. **비정상 캔들은 "진입"이 아니라 "경고"다.** 붉은 캔들이 떴다고 바로 숏이 아니다. 추세장에서는 극단 구간이 계속 이어질 수 있다(밴드 워킹).
2. **캔들색 + %R 원이 같은 방향으로 겹치는 자리**가 가장 의미 있다. 예) 파란(과매도) 캔들 구간에서 봉 아래 하늘색 원 → 하락 모멘텀 소진 + 극단 이탈 동시 확인.
3. **반대로 캔들색과 원이 어긋나면 보류**한다. 단일 신호는 신뢰하지 않는다는 펀드 원칙 그대로다.
4. 최종 방향 판단은 **이치모쿠(메인) + 상태 테이블 + 다른 보조지표 정렬**로 확인한다. 이 지표는 그 정렬을 보조하는 극단·모멘텀 필터다.

---

## 6. 주의사항

- **Auto VWAP과 중복**: 같은 차트에 둘 다 올리면 동일 봉에 캔들색·원이 겹쳐 표시된다. 하나만 사용할 것.
- **`barcolor` 특성**: 캔들 몸통 전체를 불투명하게 덮는다. 원래 캔들의 양봉/음봉 색 정보는 그 봉에서 가려진다(원본 Auto VWAP과 동일한 거동).
- **워밍업**: 이격도 통계 구간(기본 50)과 `max_bars_back=1000`이 필요하다. 차트 데이터가 짧으면 초반 구간에 색·마커가 나타나지 않을 수 있다.
- **컴파일 검증**: 로컬 Pine 컴파일러가 없어 정적 리뷰로만 검증했다. **TradingView 에디터에서 최종 컴파일·차트 확인이 필요하다.**
