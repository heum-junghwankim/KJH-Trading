# Volume-Pressure-Tracker (거래량 압력)

아래 패널에 그리는 지표입니다. 대상 스크립트: [`volume-pressure-tracker.pine`](./volume-pressure-tracker.pine) (Pine Script v6)

## 한 줄 정의

봉마다 거래량을 종가 위치로 **매수 몫과 매도 몫으로 나눠 추정**하고, 거래량이 평소보다 큰지 보여줍니다. 실제 체결 데이터가 아니라 "종가가 고가 쪽이면 매수 몫이 크다"는 근사입니다.

## 계산

    매수 몫 = 거래량 × (종가 − 저가) / (고가 − 저가)
    매도 몫 = 거래량 × (고가 − 종가) / (고가 − 저가)      (고가 = 저가인 봉은 거래량을 반씩)
    비정상  = 거래량 > SMA(거래량, 20) × (1 + 1.0)         → 20봉 평균의 2배 초과

평균에 현재 봉도 들어가므로 "2배 초과"는 직전 19봉 평균 대비 약 2.11배 초과와 같습니다.

## 차트에서 읽는 법

| 요소 | 뜻 |
| --- | --- |
| 막대 | 전체 거래량(매도색) 위에 매수 몫(매수색)을 겹쳐 그림. 위쪽 매도색 부분 = 매도 몫 |
| 막대 색 | 평소: 매수 흰색 · 매도 회색. 비정상 봉: 매수 라임 · 매도 빨강 |
| 주황 선 | 거래량 20봉 평균 |

## 우측 상단 테이블 (3행)

| 행 | 판정 | 표시 |
| --- | --- | --- |
| `거래량 압력` | 이번 봉 거래량 > 20봉 평균이고 종가 > 봉 중간값((고가+저가)/2) → `롱 유리`(녹). 거래량 > 평균이고 종가 < 중간값 → `숏 유리`(빨강). 거래량 ≤ 평균이거나, 종가 = 중간값이거나, 고가 = 저가 → `중립`(회색) | 글자 |
| `압력 방향` | 최근 5봉 매수 몫 합 ÷ 매도 몫 합. 큰 쪽이 작은 쪽의 1.2배 초과면 그 방향(`매수 (R : 1.0)` 녹 / `매도 (1.0 : R)` 빨강), 아니면 `중립 (R : 1.0)` | 1.0 = 작은 쪽 |
| `평균선(SMA)` | 최근 5봉 평균 거래량 ÷ 20봉 평균. 1.2 초과 `상회`(녹), 1/1.2(≈0.83) 미만 `하회`(회색), 그 사이 `보통` | 1.0 = 20봉 평균 |

`압력 방향`의 1.2배는 5봉 거래량 중 매수 몫이 약 54.5%를 넘는다는 뜻입니다. `하회`를 빨강으로 쓰지 않는 이유는 "거래량이 적다"를 "매도"로 오독하지 않게 하려는 것입니다.

## 핵심 파라미터 (기본값)

비교 캔들 수 20 · 비정상 배수 1.0 · 평균선 20 · 비교 봉 수 N = 5 · 임계 k = 1.2. 바꾸려면 알고리즘 수학자 검토를 먼저 받습니다.

## 잘 맞는 국면 / 약한 국면

- 돌파나 급변 봉에 거래량이 실렸는지 확인할 때 유용합니다.
- 꼬리가 긴 봉, 갭, 장중 왕복이 큰 봉은 종가 위치 추정이 실제 매수·매도와 크게 다를 수 있습니다.
- 일반론이며 펀드 데이터로 검증하지 않았습니다.

## 초보가 흔히 하는 실수

- 장중 `중립`을 "힘이 없다"로 읽기. 형성 중인 봉은 거래량이 덜 쌓여 평균보다 작게 나오기 쉽습니다. 테이블은 마지막 봉(형성 중 포함) 값이므로 마감 후에 봅니다.
- 라임/빨강 막대를 매수/매도 신호로 쓰기. 큰 거래량은 추세 시작에도, 투매·과열 같은 추세 끝에도 나옵니다.

## 주의

- 방향을 알 수 없는 봉은 어느 쪽에도 넣지 않습니다. 종가가 봉 정중앙이거나 고가 = 저가인 봉은 거래량이 커도 `거래량 압력`이 `중립`입니다. 고가 = 저가인 봉은 막대와 `압력 방향` 합계에서 매수·매도를 반씩 나눕니다.
- 5봉 합의 작은 쪽이 0이면 `중립 (-)`, 20봉 평균이 0이면 `보통 (-)`로 표시합니다.
