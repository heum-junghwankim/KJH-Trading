# cRSI (RSI Cyclic Smoothed)

트레이딩뷰용 Pine Script 보조 지표 설명서입니다.

대상 스크립트:
- [`rsi-cyclic-smoothed.pine`](./rsi-cyclic-smoothed.pine)

> Pine Script **v6** 기준입니다(v4에서 마이그레이션, 신호·계산·파라미터 동작은 동일하게 보존).

이 지표는 기본 `RSI`에 **지배 사이클(Dominant Cycle)** 기반의 평활화와 **동적 과매수/과매도 밴드**를 더한 버전입니다. 고정된 `30 / 70` 기준 대신, 최근 사이클 구간에서 cRSI가 실제로 머문 범위를 기준으로 상·하단 밴드를 계산해 줍니다. 원작은 Lars von Thienen의 *Decoding The Hidden Market Rhythm*(2017) 4장에서 소개된 cRSI입니다.

## 현재 소스 기준으로 보이는 것

| 요소 | 현재 표시 방식 |
| --- | --- |
| CRSI (기본 차분한 골드 선) | 사이클로 평활화한 RSI 본선입니다. 하늘색 밴드, 녹·적 원 마커와 대비되도록 기본 차분한 골드(`#E6B800`, 밝은 노랑보다 명도·채도를 낮춘 골드 톤)로 표시하며, `선 색상` 그룹의 `cRSI 선 색` 입력으로 원하는 색을 고를 수 있습니다. 노랑 계열은 주황(수축) 배경과 색상이 인접하므로, 수축 구간에서는 배경 대비가 다소 약해질 수 있습니다. |
| HighBand / LowBand (기본 밝은 하늘색/시안 선) | 최근 사이클 메모리 구간에서 동적으로 계산한 과매수/과매도 밴드입니다. 상·하단 모두 기본 밝은 하늘색/시안(`#4DD0E1`, Material Cyan 300 계열)으로 표시하며, `선 색상` 그룹의 `상단밴드(HighBand) 색`·`하단밴드(LowBand) 색` 입력으로 각각 원하는 색을 고를 수 있습니다. **밴드 상·하단(HighBand/LowBand) 값은 우측 프라이스 스케일(가격 축) 라벨에 표시됩니다.** |
| 과매도/과매수 참고 점선 (은색) | 참고용 고정 기준선입니다. 기본 `30`(과매도)·`70`(과매수)이며, `수축 돌파 마커` 그룹의 `과매도 참고 레벨`·`과매수 참고 레벨` 입력으로 조정할 수 있습니다(참고 점선 표시 전용입니다). |
| Band Width Background | 밴드폭이 좁으면 진한 주황색(수축), 넓으면 보라색(확장) 배경으로 강조합니다. 불투명성 기본 15(0=투명, 100=진함)로 연하게 깔립니다. |
| 수축 돌파 원 마커 (녹색/빨강) | 밴드폭 수축(주황) 구간에서 cRSI가 밴드를 **실제로 돌파(crossover/crossunder)** 할 때 **해당 밴드선 위치**에 표시하는 원 마커입니다. **녹색 원**(상단밴드 위치)=골든(cRSI가 상단밴드 상향 돌파), **빨강 원**(하단밴드 위치)=데드(cRSI가 하단밴드 하향 돌파). 밴드 위치(과매도/과매수 인근) 조건 없음. **한 수축 구간당 골든·데드가 각각 최초 1회만** 표시됩니다(같은 수축 구간의 두 번째 이후 크로스는 억제, 구간이 새로 시작되면 리셋). 기본 표시(`수축 돌파 원 마커 표시` 토글). 자세한 조건은 아래 "수축 돌파 원 마커" 항목 참고. |
| 밴드 교차 가격 테이블 (기본 우측 상단) | 직전봉 확정 데이터로 역산한 "현재봉이 이 종가로 마감하면 cRSI가 밴드를 넘나드는" 조건 가격 4행(`상단 돌파`/`상단 이탈`/`하단 돌파`/`하단 이탈`). 아래 "밴드 교차 가격 테이블" 항목 참고. **종가 기준 조건 가격이며 매매 신호가 아닙니다.** |

참고(축 라벨 표시):
- 우측 **프라이스 스케일(가격 축) 라벨에는 CRSI 본선 값과 함께 밴드 상·하단(HighBand/LowBand) 값**이 표시됩니다. 현재 과매수/과매도 경계가 축에서 바로 읽힙니다.

참고:
- 기본값은 `Dominant Cycle Length = 20`이며, 내부적으로 RSI 길이 `cyclelen = 10`, 사이클 메모리 `cyclicmemory = 40`으로 환산됩니다.
- `vibration = 10`, `leveling = 10.0`은 코드 내부 상수로 고정되어 있습니다(입력값 아님).
- 동적 밴드는 사이클 메모리(`40봉`) 구간에서 cRSI 값의 분포를 백분위로 훑어, 하위 `10%`(LowBand)·상위 `10%`(HighBand) 경계를 잡습니다.
- 밴드폭 배경은 `bar_index < cyclicmemory`(초기 구간)에서는 표시되지 않습니다.

## cRSI를 쓰는 이유

일반 RSI는 `30 / 70` 같은 고정 기준을 쓰지만, 종목·국면에 따라 RSI가 실제로 도는 범위가 다릅니다.

- 추세장에서는 RSI가 한쪽에 쏠려 `70`을 계속 넘겨도 과매수로 보기 애매합니다.
- 횡보장에서는 `30 / 70`에 닿기 전에 이미 반전하기도 합니다.

cRSI는 사이클로 평활화해 노이즈를 줄이고, **최근 구간에서 cRSI가 실제로 머문 범위**로 밴드를 그려 "지금 국면 기준으로 과한지"를 봅니다.

## 트레이딩 의미 핵심

### 1. cRSI가 LowBand 아래일 때

`최근 사이클 기준으로도 과하게 눌린 구간`을 뜻합니다.

- 고정 `30`보다 그 국면에 맞는 과매도 경계라서, 횡보·추세 양쪽에서 더 현실적인 자리로 봅니다.
- 단독 진입보다는 `되돌림 감시 자리`로 보는 편이 맞습니다.

### 2. cRSI가 HighBand 위일 때

`최근 사이클 기준으로도 과하게 올라간 구간`을 뜻합니다.

- 급등 뒤 상승 피로를 보는 데 유용합니다.
- 메인 신호가 약해지는 자리와 겹치면 `후행 롱 자제`, `숏 감시` 의미가 커집니다.

### 3. 밴드폭 배경(진한 주황색 / 보라)

밴드폭(`HighBand - LowBand`)은 변동성/사이클 진폭의 대리 지표입니다.

- **진한 주황색(좁은 밴드)**: cRSI가 좁은 범위에서만 움직이는 `수축 구간`. 큰 움직임 직전의 눌림일 수 있어, 밴드 돌파 방향을 주시합니다.
- **보라(넓은 밴드)**: cRSI가 크게 출렁이는 `확장 구간`. 신호가 자주 극단에 닿으므로 과매수/과매도 신호의 신뢰도를 한 번 더 거릅니다.

## 내부 로직

1. `cyclelen = domcycle / 2` 길이로 기본 RSI를 계산합니다.
2. `torque`, `phasingLag`(vibration 기반)로 cRSI를 사이클 평활화합니다.
   - `crsi := torque * (2*rsi - rsi[phasingLag]) + (1 - torque) * crsi[1]`
3. 최근 `cyclicmemory(= domcycle * 2)`봉 구간에서 cRSI의 최댓값/최솟값을 찾습니다.
4. 그 범위를 100단계로 나눠, 분포의 하위 `leveling%`(LowBand)·상위 `leveling%`(HighBand) 경계를 백분위로 잡습니다.
5. 밴드폭으로 배경색(수축/확장)을 칠합니다.

즉 고정 임계선이 아니라, `현재 국면에서 cRSI가 실제로 돈 범위`를 기준으로 과매수/과매도를 판단하는 방식입니다.

> 기존 우측 상단 **cRSI 상태판**(`포지션`·`cRSI 값(밴드폭)`·`모멘텀` 3행)은 CEO 지시로 **제거**되었습니다. 상태판 전용 판정 로직(수축 돌파 지속 래치 `crsiBreak`, 확장 다이버전스 래치 `crsiDiv`, 모멘텀 5분류 `crsiSlope`/`slopeEps`, `포지션` 판정)도 함께 삭제됐으며, 차트 마커·배경·밴드 동작은 변하지 않습니다. 밴드폭 수축/확장 상태는 배경색으로, 확장 다이버전스는 ▲▼ 마커로 확인합니다. 이제 차트의 테이블은 아래 **밴드 교차 가격 테이블** 하나뿐입니다.

## 밴드 교차 가격 테이블

기본 **우측 상단**(auto-vwap 테이블과 같은 위치)에 헤더 없는 4행 테이블이 표시됩니다. 각 행은 "**현재봉이 이 종가로 마감하면** cRSI가 해당 밴드 조건을 만족하는 경계 가격"이며, 2열에 `가격 (직전 종가 대비 부호 포함 %)` 형식으로 표시합니다 — 예: `12,345.6 (+2.31%)`.

- **가격 포맷**: 천 단위 쉼표 + 종목 `syminfo.mintick` 소수 자릿수(예: `1,000` / `12,345.6` / 틱 0.25 종목 `12,345.25`). auto-vwap의 `#,##0.0…` 포맷 방식과 같으며, 자릿수는 `mintick × 10^d`가 정수가 되는 최소 `d`(최대 8)로 정해 0.25·0.005 같은 틱도 자릿수가 잘리지 않습니다. %는 소수 2자리 부호 포함 `(+2.31%)` 그대로입니다.
- **행 배경색**: `상단 돌파`·`하단 돌파` 행=녹색 `#2E7D32`, `상단 이탈`·`하단 이탈` 행=적색 `#C62828`(펀드 공용 녹/적 팔레트), 흰 글자. 라벨 셀 투명도 20(진하게)·값 셀 투명도 40(옅게). 값이 `-`인 비활성 행은 라벨 65·값 80으로 흐리게 처리해 현재 상태에서 의미 있는 행이 눈에 띕니다(`도달불가`는 활성 행으로 취급).

> **종가 기준 조건 가격이며 매매 신호가 아닙니다.** 장중 가격이 이 값을 스쳐도, 봉 마감 종가가 조건을 충족해야 cRSI가 실제로 밴드를 넘습니다. 이치모쿠·테이블·타 보조지표 정렬 확인용 참고값으로만 씁니다.

| 행 | 의미 (현재봉 종가 조건) | 값이 표시되는 상태(직전봉 확정 기준) |
| --- | --- | --- |
| `상단 돌파` | 종가 ≥ 이 가격 → cRSI ≥ 상단밴드(ub) | 중간(밴드 안) |
| `상단 이탈` | 종가 ≤ 이 가격 → cRSI < 상단밴드(밴드 안 복귀) | 상단 위(`crsi[1] >= ub[1]`) |
| `하단 돌파` | 종가 ≥ 이 가격 → cRSI > 하단밴드(밴드 안 복귀) | 하단 아래(`crsi[1] <= db[1]`) |
| `하단 이탈` | 종가 ≤ 이 가격 → cRSI ≤ 하단밴드(db) | 중간(밴드 안) |

- **상태별 표시**: 하단 아래 → `하단 돌파`만, 중간 → `상단 돌파`·`하단 이탈`만, 상단 위 → `상단 이탈`만 값을 보이고 나머지 행은 `-`입니다. 초기 봉 등 준비가 안 된 구간(`bar_index < cyclicmemory + cyclelen + phasingLag + 1` 또는 값 없음)은 4행 모두 `-`입니다.
- **`-`**: 해당 상태에서 의미 없는 행이거나, 계산 데이터가 없음(직전봉 `up`·`down`이 모두 0 등).
- **`도달불가`**: 목표 cRSI를 만들 RSI가 0 이하·100 이상이 필요하거나, 역산 가격이 0 이하라 **어떤 종가로도 이번 봉에 도달할 수 없는** 경우입니다.
- **부호**: 계산값 그대로 표시합니다. cRSI 평활 관성 때문에 `하단 돌파`가 `−%`(더 내려도 복귀), `상단 이탈`이 `+%`(더 올라도 이탈)로 나올 수 있으며 정상입니다.
- **틱 반올림**(`syminfo.mintick`): 조건을 확실히 만족하는 쪽으로 맞춥니다 — `상단 돌파` 올림, `하단 이탈` 내림, `상단 이탈` 내림(정확히 틱 위면 −1틱, 엄격 `<`), `하단 돌파` 올림(정확히 틱 위면 +1틱, 엄격 `>`). %는 반올림된 가격 기준입니다.
- **리페인팅 없음**: `close`·`crsi[0]`·`ub[0]`·`db[0]`을 쓰지 않고 직전봉 확정값(`up[1]`, `down[1]`, `crsi[1..cyclicmemory−1]`, `rsi[phasingLag]`, `close[1]`)만 쓰므로 **현재봉 동안 값이 고정**됩니다. 단, 장 마감 후처럼 마지막 봉이 이미 확정된 경우에도 그 마지막 봉을 "현재봉"으로 보고 계산합니다.

계산 방식(알고리즘 수학자 확정 사양):
1. **목표 cRSI**: `ub[1]`/`db[1]`이 아니라 `crsi[1..cyclicmemory−1]`로 기존 밴드와 같은 백분위 격자를 돌려 얻은 정확 임계값 `U*`/`D*`를 씁니다(현재봉 cRSI ≥ ub ⇔ ≥ U*, ≤ db ⇔ ≤ D* 동치, brute-force 검증).
2. **목표 RSI**: `crsi = τ·(2·rsi − rsi[phasingLag]) + (1−τ)·crsi[1]`을 rsi에 대해 역산 → `r* = ((T − (1−τ)·crsi[1]) / τ + rsi[phasingLag]) / 2`.
3. **목표 종가**: `rma` 갱신식(`up`/`down`, 길이 `cyclelen`)을 가격 변화 Δ에 대해 역산 → `P = close[1] + Δ`.
4. 무거운 루프(약 2×101×39회)는 마지막 봉(`barstate.islast`)에서만 돕니다.

## 수축 돌파 원 마커

밴드폭이 **수축(진한 주황색 배경)** 인 구간은 큰 움직임 직전의 눌림일 수 있어, 밴드 돌파 방향을 주시합니다. cRSI가 밴드를 **실제로 돌파하는(`ta.crossover`/`ta.crossunder`)** 시점에 원을 찍습니다(골든=상단밴드 ub, 데드=하단밴드 db). **밴드 위치(과매도/과매수 인근)와는 무관**합니다. **한 수축 구간(주황 배경이 연속으로 이어지는 한 구간)당 골든·데드가 각각 최초 1회만** 표시됩니다.

| 마커 | 조건 | 의미 |
| --- | --- | --- |
| 녹색 원 (골든, 상단밴드 위치) | 당봉 수축(현재 봉이 주황 배경, `narrowBw`) **AND** cRSI가 상단밴드(ub)를 상향 돌파(`ta.crossover(crsi, ub)`) **AND** cRSI 진행방향 게이트(`crsi > crsi[1]`, 상승 중) | 수축 국면에서 cRSI가 상단 밴드를 뚫는 반등 방향 → 롱 관점 |
| 빨강 원 (데드, 하단밴드 위치) | 당봉 수축(현재 봉이 주황 배경, `narrowBw`) **AND** cRSI가 하단밴드(db)를 하향 돌파(`ta.crossunder(crsi, db)`) **AND** cRSI 진행방향 게이트(`crsi < crsi[1]`, 하락 중) | 수축 국면에서 cRSI가 하단 밴드를 이탈하는 하락 방향 → 숏 관점 |

- **실제 돌파 시점**: cRSI가 밴드를 **실제로 교차하는 봉**에서 표시합니다 — 골든 `ta.crossover(crsi, ub)`(직전 봉 `crsi ≤ ub` → 당봉 `crsi > ub`), 데드 `ta.crossunder(crsi, db)`(직전 봉 `crsi ≥ db` → 당봉 `crsi < db`). 위치 무관·마진 없음입니다.
- **cRSI 진행방향 게이트(골든=상승 중·데드=하락 중, 밴드 밀림 유사교차 억제)**: 골든은 `crsi > crsi[1]`(cRSI가 상승 중), 데드는 `crsi < crsi[1]`(cRSI가 하락 중)일 때만 발화합니다. 동적 밴드(`ub`/`db`)가 밀리면서 cRSI를 스쳐 발생하는 **유사교차**(cRSI 자체는 반대 방향으로 진행 중인데 밴드가 밀려 크로스로 잡히는 경우)를 차단하고, cRSI가 실제로 돌파 방향으로 진행할 때의 정상 돌파는 유지합니다. 확장 마커(`goldenExpand`/`deadExpand`)와 동일한 전례입니다. `crsi[1]`은 확정된 직전 봉 값이라 리페인팅을 유발하지 않습니다.
- **수축 구간당 각 1회 제한(래치)**: 한 수축 구간(`narrowBw`가 연속 true인 한 구간) 동안 **골든은 최초 1회, 데드도 최초 1회만** 표시합니다. 같은 수축 구간에서 두 번째 이후 크로스는 억제되고, 수축 구간이 **새로 시작되면 래치를 리셋**해 그 구간에서 다시 각 1회 허용합니다. 골든/데드는 서로 **독립 래치**(`goldenFiredNarrow` / `deadFiredNarrow`)입니다. `ta.crossover`/`ta.crossunder`는 한 번 뚫은 뒤 밴드 안으로 되돌아왔다가 같은 구간에서 재차 뚫으면 다시 참이 되는데, 이 래치가 그 두 번째 이후 발화를 막습니다. 래치 set은 **확정봉(`barstate.isconfirmed`) 기준으로 마커가 실제 표시된 봉에서만** 일어나므로, 미마감봉에서 조기 설정돼 확정 시 어긋나는 문제는 없습니다.
- **"수축 구간" 정의(마커)**: **당봉 수축**(`narrowBw` — 현재 봉이 주황 배경)만 인정하며, 구간 시작은 `narrowBw and not narrowBw[1]`(직전 봉은 수축이 아니었던 첫 봉)로 판정합니다.
- **확정봉 기준**: `barstate.isconfirmed`가 참인 **마감(확정) 봉**에서만 원을 찍어 미마감봉 점멸을 막습니다.
- **리페인팅 주의**: cRSI와 동적 밴드(db/ub)는 최근 사이클 메모리 구간의 재계산에 기반하므로, **이론적으로는** 새 봉이 만들어질 때 과거 밴드 값이 미세하게 변동해 확정봉이라도 원 위치가 약간 흔들릴 수 있습니다(밴드 지표 특성상 완전 무리페인팅은 아님). 다만 확정봉 게이트로 미마감봉 점멸은 제거했습니다. 단독 진입 근거가 아니라 이치모쿠·테이블·타 보조지표 정렬과 함께 보는 확인용으로 씁니다.

> 확장(보라) 구간의 돌파 원 마커는 제거되었습니다(CEO 지시: "보라색인 경우 데드/골든 크로스는 넣지 말자"). 보라(확장) 배경 강조 자체는 그대로 유지되며, 확장 구간의 방향 판단은 다이버전스(▲▼ 마커)로 봅니다.

## 자주 만지는 설정

| 설정 | 언제 조정하나 |
| --- | --- |
| `Dominant Cycle Length` | 종목/타임프레임의 지배 사이클에 맞춰 밴드 민감도를 바꿀 때 (책의 사이클 도출 방법 참고) |
| `Narrow / Wide Band Width Threshold` | 수축/확장 배경이 켜지는 밴드폭 기준을 바꿀 때 |
| `Show Band Width Background` | 배경 강조를 끄고 선만 보고 싶을 때 |
| `밴드 배경 불투명성 (0=투명, 100=진함)` | 배경 진하기를 조절할 때. **0이면 완전 투명(안 보임)**, 100이면 가장 진함. 기본 15(연한 편) |
| `수축 돌파 원 마커 표시` | 수축 구간 밴드 돌파(crossover/crossunder) 원(녹색/빨강)을 끄고 싶을 때. 기본 켜짐 |
| `과매도 / 과매수 참고 레벨` | 참고 점선 기준(기본 30 / 70)을 바꿀 때 |
| `밴드 교차 가격 테이블 표시` / `테이블 위치` / `글자 크기` | 교차 가격 테이블을 끄거나(기본 켜짐), 위치(기본 우측 상단)·글자 크기(기본 작게)를 바꿀 때 |

## 주의사항

- `Dominant Cycle Length`는 임의값이 아니라, 원서(4장)에서 설명한 방식대로 **실제 지배 사이클을 도출해 넣어야** 의도대로 동작합니다.
- 초기 `cyclicmemory`봉 구간에서는 밴드와 배경이 안정화되지 않습니다.
- 단독 진입 근거보다, 자리·거래량·추세 지표와 함께 보는 보조 확인용에 가깝습니다.
- `vibration`, `leveling`은 현재 입력값이 아니라 코드 상수입니다. 바꾸려면 소스를 직접 수정해야 합니다.
