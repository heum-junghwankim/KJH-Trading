# cRSI (RSI Cyclic Smoothed)

아래 패널에 그리는 지표입니다. 대상 스크립트: [`rsi-cyclic-smoothed.pine`](./rsi-cyclic-smoothed.pine) (Pine Script v6)

## 한 줄 정의

RSI를 시장 사이클 길이에 맞춰 평활한 선(cRSI)과, 최근 40봉 동안 그 선이 실제로 움직인 범위로 그린 **동적 과열/침체 밴드**입니다. 고정 30/70 대신 "요즘 기준으로 높은가 낮은가"를 봅니다.

## 계산 (기본 `Dominant Cycle Length = 20`)

    RSI 길이     = 20 / 2 = 10         (RMA 방식)
    평활 계수 τ  = 2 / (10 + 1) ≈ 0.18  (vibration 10, 코드 상수)
    위상 지연    = 4봉
    cRSI        = τ × (2·RSI − 4봉 전 RSI) + (1 − τ) × 직전 cRSI
    밴드 구간    = 20 × 2 = 40봉
    하단 밴드    = 40봉 cRSI 값 중 하위 10%가 그 아래에 오는 경계
    상단 밴드    = 40봉 cRSI 값 중 상위 10%가 그 위에 오는 경계
    (경계는 40봉 최소~최대를 100칸으로 나눈 격자에서 찾으므로 근사 백분위)

## 차트에서 읽는 법

| 요소 | 뜻 |
| --- | --- |
| 골드 선 `#E6B800` | cRSI |
| 시안 선 2개 `#4DD0E1` | 상단 밴드 / 하단 밴드 (가격축에 값 표시) |
| 회색 점선 | 고정 참고선 30 / 70 (표시 전용) |
| 진한 주황 배경 | 밴드폭(상단 − 하단) ≤ 20 → 진폭 수축 |
| 보라 배경 | 밴드폭 ≥ 35 → 진폭 확장 |
| ▲ 녹 / ▼ 빨강 | 상승 / 하락 다이버전스 (보라 배경일 때만) |

다이버전스: cRSI 피벗(좌우 5봉)끼리 비교해, 가격은 더 낮은 저점인데 cRSI는 더 높은 저점이면 상승(하락은 대칭). 직전 피벗과의 거리는 5~60봉.

## 밴드 교차 가격 테이블 (우측 상단, 4행)

| 행 | 값이 나오는 상태 | 뜻 |
| --- | --- | --- |
| `상단 돌파` (녹) | cRSI가 밴드 안 | 다음 봉 종가가 이 % 이상이면 cRSI ≥ 상단 |
| `하단 이탈` (적) | cRSI가 밴드 안 | 다음 봉 종가가 이 % 이하이면 cRSI ≤ 하단 |
| `상단 이탈` (적) | cRSI ≥ 상단 | 다음 봉 종가가 이 % 이하이면 밴드 안으로 복귀 |
| `하단 돌파` (녹) | cRSI ≤ 하단 | 다음 봉 종가가 이 % 이상이면 밴드 안으로 복귀 |

- 해당 없는 행과 해가 없는 경우는 `-`(어두운 톤).
- 값이 **노랑 굵게** = 돌파 행이 `−%` 또는 이탈 행이 `+%`. 보합이나 반대 방향 소폭 움직임으로도 다음 봉에 교차한다는 뜻(평활 관성 때문, 정상).
- `테이블 기준봉`: `실시간봉`(기본) = 현재 봉 기준, 틱마다 갱신, 봉 마감 시 값은 완성봉 모드와 같음. `완성봉` = 최근 마감 봉 기준, 고정.

## 잘 맞는 국면 / 약한 국면

- 사이클이 비교적 규칙적인 박스·완만한 추세에서 밴드 이탈·복귀가 의미 있게 나옵니다.
- 강한 추세에서는 밴드도 따라 움직여 cRSI가 한쪽 밴드 근처에 붙어 있을 수 있습니다.
- 일반론이며 펀드 데이터로 검증하지 않았습니다.

## 초보가 흔히 하는 실수

- 다이버전스 삼각형을 실시간 신호로 쓰기. 피벗 확인에 오른쪽 5봉이 필요해 **5봉 늦게, 5봉 과거 위치에** 찍힙니다. 보라 배경 조건은 확인 시점의 봉에서 판정합니다.
- 하단 밴드 아래 = 바닥으로 읽기. 밴드는 최근 40봉 분포라 하락 추세에서 함께 내려갑니다.

## 주의

- `Dominant Cycle Length`는 원서(4장) 방법으로 실제 사이클을 구해 넣는 값입니다. 20은 기본값일 뿐입니다.
- 처음 40봉은 밴드가 안정되지 않으며 배경도 그리지 않습니다.
- `vibration`(10)과 `leveling`(10%)은 입력이 아니라 코드 상수입니다.
- 기간·임계값은 전략 파라미터입니다. 바꾸려면 알고리즘 수학자 검토를 먼저 받습니다.
